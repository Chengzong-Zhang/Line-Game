# 微信小游戏

本整合分支的实际小游戏源码在 [minigame/](minigame/)，官方构建/上传工具在 [ci/](ci/)。从相应 package.json 和 README 读取当前构建命令；不要把旧平台工作树当成本分支新版本。

本轮以最新完成的网页与小游戏能力作为跨平台整合基准。上传、预览、后台体验版指向、真机、审核和公开是不同状态，详见 [本轮平台审计](../working/docs/maintenance/alignment-20261031/PLATFORM-AUDIT.md)。

本机可选 `project/` 链接只作既有独立工作树导航；它可能指向历史分支。修改前检查真实目标、分支与差异，不通过目录链接覆盖或递归清理源码。
