# 基于现有模型的防守继续训练结果（2026-10-25）

本轮实际训练已经完成：21 个既有父模型产生 21 个主批次候选（4 个线性、17 个神经），另产生 2 个六人专用线性候选。23 个候选各更新 100 次，共 2,300 次参数更新；全部继承原权重并保留父哈希，按新协议重置优化器和随机状态。这是有界的监督式策略微调，不是重跑原 DQN/PPO/SAC 等强化学习过程。候选尚未获产品棋力准入，**没有替换网页或微信的线上权重**。

主批次使用 172 个完整防守标签，额外六人批次使用 6 个标签。按人数 2/3/4/5/6，实际最大展开深度分别达到 4/6/8/10/12 层；所有根合法动作与 PASS 都参与精确比较，未完成的搜索未用作标签。允许其他分支正常提前终局。整场游戏划分训练与验证，联合源未发现跨 split 的相同 episode、完整状态或剥除历史后的相同盘面。

17 个神经模型仅用双人三角形的 61 个训练、62 个验证位置；17/17 留出 CE 降低，教师最优动作一致率 14 个提高、2 个不变、1 个下降。六人额外候选的原父模型为 Easy/Hex，各用 4 个三角形七路训练位置、2 个六边形五路验证位置，CE 分别 0.463247→0.351245、0.818536→0.546225；原模型和候选在这两个验证位置本来都选中教师最优动作。样本少且配置偏移，不能称六人原生六边形棋力已经改善。

主批次四个线性候选完成 34/34 局自然终局对照，无截断。三组三人对照的候选轨迹与控制相同；四人 Hex 的平均获胜份额差 +0.125，但由单个种子驱动，己方节点/覆盖损失反而更高，重复受切没有减少。每组只有两个独立种子块；这些对局不证明总体胜率或防守增强，也没有覆盖神经候选和六人对局。

独立核验已检查数据、源/父模型/候选哈希、完整检查点、全部神经资产和数值合法性，并重放 1,134 个评估动作及 136 个开局动作。17 个神经资产均确实改变。12 个图网络的 value 参数字节未变，但主干改变使 value 输出变化，最大绝对漂移约 0.803920；3 个旧图模型仍缺主动 PASS 运行时契约。部分防守指标退步，候选保持隔离。
