# 本轮审阅澄清

本文件补充固定训练与评估证据，不改写已冻结模型或训练源。

## 独立 PASS / value 头的范围

研究网络存在独立 PASS / value 头，其参数不参与本轮梯度更新。
五个 model-free MLP 的整块动作头继续训练：小棋盘用于 PASS 的动作索引，
在更大棋盘可能对应落点，因此不能称 model-free 的全部 PASS 参数冻结。
冻结候选元数据中的通用 `pass_head_frozen` 标志只适用于存在独立 PASS 头的结构；
真实参数范围见训练源码及独立验证报告。共享骨干更新也会改变继承头的预测输出。

MLP 网页适配器在存在合法落点时过滤 PASS；本轮数值对照比较的是过滤后重新归一化的
条件落点概率，不是包含主动 PASS 的完整策略。对战使用同一网页适配器，没有改写该行为。

新蒸馏数据覆盖 5–15，旧 `trained_board_sizes` 与 checkpoint 字段保留父模型来源。
当前训练范围、当前权重和检查点 hash 由本轮数据与训练收据记录。

## 双人对战工具的新版本

校准及初版恢复测试使用 `neural-posttraining-arena.mjs`。审阅发现，初版仅在
身份中绑定父权重，未绑定能影响推理的父 manifest 元数据；正式 204 局使用新增
`neural-posttraining-arena-v2.mjs`，将三份父 manifest 原字节 hash 一并绑定。
旧校准源和证据保留，不把旧校准声称为正式评估完成。

新版还对已写入但未索引的完整对局采用“内容一致才采用，损坏则停止”的方式，
防止覆盖异常证据；新版验证器独立核对全部结果计数和分尺寸汇总。

## 已完成双人数据的恢复边界

数据生成任务实际完成 66 条轨迹，4 次正常预算切片，0 异常退出。
全部 1,792 个动作、特征、关系、合法 mask 已重放核验，22 个分层教师标签重新计算。
原生成器在“完整 episode 写入后、索引提交前”中断时，会根据已保存的动作和样本
重写同名单元；它不会重新采样，但不专门保留该未索引文件的异常内容。
这一未来恢复路径的证据保留缺口已记录。当前完整数据未出现该故障并已通过全量重放，
不因该发现修改正在被训练任务绑定的生成源或重造数据。

未来运行入口 `neural-posttraining-data-v2.mjs` 已补齐完整孤立文件采用和损坏保留，
并通过独立 fixture 的真实中断恢复测试。本轮 66 条轨迹继续引用原 v1 生成源，
不把 v2 的恢复测试写成本轮数据由 v2 生成。

## 双人筛查的统计和复核范围

每模型 12 局来自 6 个配对开局；17 模型共享这些开局。204 是对局数，
不是 204 个独立样本，也不是对 17 个模型同时成立的提升证明。
v2 验证器重放全部动作历史、终局面积和所有汇总字段，但仅重新计算每局首个和
中间策略决定；不称为全部策略决定重算。棋力筛查只覆盖尺寸 5 / 7 / 9。

已训练双人候选、三人 v3 和六边形 v2 的强度判定分别报告，不能用损失下降、
数值 parity 或恢复测试代替棋力证据。
