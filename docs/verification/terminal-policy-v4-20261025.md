# 终局回报继续训练与 PASS 修复

状态：实现和有界恢复验证中，正式训练、准入及发布收据另行记录。此文件不声称新权重已上线。

按用户要求，环境的每个非终局奖励严格为 0，折现因子为 1。仅当规范引擎自然结束整局时计算回报。令 `N` 为棋盘格点数，`A_i` 为原生离散终局面积，`M_i=A_i-maxOpponentArea`，采用 `R_i=sign(M_i)+0.1*M_i/N+0.01*A_i/N`。胜负占主导，最终分差和最终面积区分同样胜负下的扩张收益；没有中间线长、暂时面积、游戏时长或提前获胜奖励。截断对局不补为平局，不产生回报或参数更新。

从既有 easy、three-v4、three-v1、hex-v1 的 16 个系数继续训练，保留父模型 ID、文件哈希和原始系数。原温度吸收到系数中；新增 PASS 系数由 0 开始。使用逐自然终局 REINFORCE，优化器重置，不把此次继续训练称为原实验 resume，也不声称原神经网络已重训。

梯度样本必须有新完成的完整合法动作 Minimax（包括 PASS）：至少 3 层，实际要求 `max(3, 2*存活席位数)`。按规范引擎的真实行动方推进，保留逻辑边、出生点、Superko 历史、PASS 与版本。深搜仅产生固定防守 mask 和样本资格，叶子估值不是环境奖励。多动作 mask 内按正确归一化策略采样并计算 log 概率梯度；单动作、超时、提前终局导致实际深度不足及未选中状态仅为整局上下文。该选态和 mask 引入的范围限制必须随覆盖结果报告，不能据此宣称全局策略梯度结论或普遍棋力提升。

运行时移除“PASS 立刻独胜就无条件优先”的捷径。对于策略本来选择 PASS 的局面，在隔离引擎中检查保留全部节点、线与起点连通、离散面积有收益的落点；枚举到当前玩家下一次实际行动前的完整对手行动轮，包括所有合法落点和 PASS。第三席能切断时不能用第二席的安全结果代替。预算不足不声称已证安全，也不把没有模型输出当主动 PASS。

继续训练后的系数通过独立 overlay 接入，不覆盖父模型文件。三人 V4 保留原搜索过程，使用新 placement 系数；其线性 PASS 系数不会与搜索值直接混比。旧 v2 存档保留原模型参数。发布准备拒绝带有模型但仍标为 `EVALUATION_ONLY` 的 overlay；正式激活需要独立组合准入报告的哈希。

检查点逐行动保存完整引擎状态、RNG、模型、优化器计数、基线、episode 进度和参数更新事务；逐行动/逐 episode 收据增量持久化。独立监督者保留原截止时间、独占锁、有界恢复、PAUSE/STOP 和登录恢复。测试覆盖实际强杀 worker、强杀监督者、提交边界中断、未索引收据接纳、与干净运行参数/计数一致、重复启动拒绝及损坏停机。
