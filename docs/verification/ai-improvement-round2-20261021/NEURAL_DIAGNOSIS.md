## 当前优先动作

对七个固定候选使用全新 seed，在尺寸 5 / 7 / 9 上各取 10 个开局并交换席位：每模型 60 局、30 个配对开局簇，总计 420 局。既有训练候选和网页推理预算不变。

独立 assessment 的预定门为：60 局全部自然终局、平均对局得分至少 0.55、每尺寸至少 0.45，且七项单侧精确符号检验经过 Holm step-down 校正后在 FWER 0.05 下拒绝零假设。每簇的差为两次换色得分平均值减去 0.5，零差簇从符号检验中排除。

符号检验的联合零假设是“每个固定尺寸层中，非零差开局出现正差的条件概率均不超过 1/2”，并要求非零簇符号独立；**不是平均得分差等于零的检验，也不能只要求混合后的平均正差概率不超过 1/2**。各尺寸层不必同分布；所有保留符号的正差概率均为 1/2 时，二项分布尾概率为精确边界值，其他满足上述联合零假设的情形保守有效。七模型共享开局会产生模型间相关性；Holm 不要求这些 p 值相互独立。统计解释仍依赖预定 seed 抽样机制与开局簇的适当独立性，不能把同簇两局当两个独立样本。按尺寸分层的 10,000 次簇 bootstrap 使用每模型 seed：基础值 2026102137 与模型 ID 的 SHA-256 前八位十六进制整数作 XOR，再转为 uint32。其 95% 区间仅作描述，不宣称为七模型同时置信区间，也不作为额外选模门。

assessment 必须读取已通过的 v2 全字段对战验证及执行退出收据，重哈输入、核对完整配对计划，并从 game 文件独立重放合法历史、计算终局面积和汇总成绩。输出写入单独的 `confirmation-assessment.json`；原始 `summary.json` 的 `promotionPass: false` 保持不变。

## 后续训练假设

以下都是可检验的改进假设，目前不能归因于实际输棋原因：

1. 单一 Minimax depth 2 的启发式分布并非终局收益目标，且根与回复各限制 20 个候选；把其 CE 压低不能保证面对原始神经策略时更强。
2. 既有数据主要来自教师/随机行为，可能欠缺候选自己对弈时常到的局面。
3. 上轮虽冻结独立 value/PASS 头，其共享骨干仍被更新，Research PUCT 使用的价值输出可能因此变化。只监督 policy 的更新不能单凭冻结头参数声称 value 预测不变。

若之后需要新增训练，优先采用保守的 policy-head-only 试验：冻结共享表示和独立 value/PASS 头，只更新 Research 的 `point_policy` 或 MLP 的最后动作投影。Research value 预测和独立 PASS logit 因而保持不变；归一化 PASS 概率仍可能随落点 logits 变化。MLP 的动态 PASS 行与大盘落点行共用参数，仍需明确标记，不能声称所有 PASS 参数被冻结。

可选预算为七路线最多各三阶段 × 40 次更新，合计 840 次；batch 16，学习率候选为 5e-5 → 2.5e-5 → 1e-5，以固定父策略 KL 约束变化。保存 stage 0 / 40 / 80 / 120，使用另设 DEV 对局选择，后续 FINAL 开局必须与本轮确认集及 DEV 分离。这个配置只是备选，不能据此开始长训练。

## 终局 rollout 教师的可行性与成本

更直接的目标备选是：从行为策略实际到达的局面构造有限候选动作集合，用相同 seed 的配对 rollout 比较动作，只有自然终局时使用网页离散 area 得出的共享胜利分数。候选集合可混合当前策略、启发式搜索与随机探索，避免完全继承单一教师的动作支持。截断 rollout 保留为未完成证据，不伪造终局奖励；小样本回报只能视为该 rollout 策略下的局部估计。

有界校准已运行 12 局：尺寸 5 / 7 / 9 各四局，前六步随机，其后使用 50% Greedy / 50% 均匀随机。12 局均自然终局，累计约 1.87 秒；尺寸 9 最慢约 0.387 秒/局。没有更新模型，这些局面不会直接作为正式训练样本。

一个最小数据备选是每尺寸 32 个训练局面和 16 个验证局面，合计 144 个局面；每局面最多四个候选动作，每动作两个配对 rollout，最多 1,152 条 rollout。以本次最慢小样本耗时外推，纯 rollout 约 446 秒；不包含候选动作生成、checkpoint/哈希、局面分布变化和并发负载。若采用该路线，需要重新校准并固定预算，例如数据硬上限 1,200 秒、训练硬上限 1,200 秒；不得把本次时序校准当成正式批准或完成证据。

两个 rollout 的估计方差很大，不能直接视为可靠最优动作。可以使用温度、与 anchor 混合及小步更新，但必须由独立 DEV/FINAL 检查实际收益。若当前 420 局确认已经证明部分既有候选达到门槛，应优先交付那些有证据的改进，再决定是否投入此数据路线。
