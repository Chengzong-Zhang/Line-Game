# 微信对战舱天梯 v1

2026-10-26。目标：在原生 Canvas 对战舱提供 AI 榜、人类榜，展示积分、并列名次、总局数、胜率、平局数、计分局数和自己的成绩。每页 20 人，自己的成绩不受分页影响。两榜完成 5 场计分对局后入榜；相同整数积分并列，不以账号或隐藏小数打破平分。

## AI 榜

从“对战舱 → 开始 AI 排位”进入，由服务器执行四档现有 AI。固定 7 路三角棋盘、territory-v3、默认起点、玩家蓝方先手，无提示和悔棋。保留本地人机练习，不能上传自报难度/胜负给天梯加分。

| 难度 | 现有执行器 | 系数 |
| --- | --- | ---: |
| 入门 | greedy | 1 |
| 普通 | minimax-2 | 1.5 |
| 进阶 | minimax-3 | 2 |
| 深入 | minimax-4 | 3 |

令 N 为计分局数，每局结果 s 为胜 1、平 0.5、负 0，难度系数为 d：

`AI 积分 = 四舍五入[1000 × Σ(d × s) / (N + 10) + 2 × min(N, 100)]`

前项同时体现胜率和战胜 AI 的难度，分母增加 10 局降低小样本运气；后项奖励参与，最多 200 分，不会随刷局无限增加。负局也进入分母。例：普通难度 10 局 8 胜 2 负为 620 分；相同战绩换深入难度为 1220 分。四档系数是产品初版参数，不是经过大规模实测的 AI 强度比例；未来调整必须升级评分版本，不能静默改写旧积分。

## 人类榜

共用当前微信/网页共享的双人房间身份与服务端规则裁决。实力分 R 从 1000 开始：

`预期成绩 E = 1 / (1 + 10^((对手 R − 自己 R) / 400))`

`每局实力分变化 = 16 × (s − E)`

`人类榜积分 = 四舍五入[R + 2 × min(N, 50)]`

双方使用结算前的实力分计算，不按先后写入后的值计算。实力分保留小数，仅展示积分取整。击败强者加分更多，输给强者扣分较少；参与奖励最多 100 分。等实力对局，在前 50 场内获胜约 +10、失败约 −6；奖励封顶后约为 ±8。

实力分单局最多变化 16；加上尚未封顶的参与奖励，榜单积分最多增加 18。它不能保证极小分差永不换位，但不会因为一次输赢就抹去数百分的长期优势。此版没有额外的隐藏“保级”或主观加分。

## 计分边界

- 只统计启用此版后的 V3 联机对局及服务器 AI 排位；旧房间、V1/V2 历史记录不回填。普通本地 AI、双人同屏、教学、复盘和导入棋谱不进入榜单。
- 人类联机采用默认起点且实际没有悔棋，才可计分。其他新 V3 对局只记战绩。正常终局双方各需至少 2 次有效落子；开局直接互相 PASS 不计分。认输、主动离房按负结算，不能靠退出逃掉已开始的排位。
- 同一人类对手每天前 3 场可计分；AI 每天前 20 场可计分。按北京时间零点重置。超限对局仍计总战绩，不增加计分局数、资格进度、参与奖励或实力分。
- 掉线可以重连，不立即扣分。房间连续 24 小时无操作到期后，当前行动方按认输结算；在下一次榜单读取或创建房间清理时持久化。等待双方准备的房间不作负局。已结算对局不能再悔棋；再来一局生成新的对局 ID。
- 胜率为胜局 / 总局数，平局单列；计分局数独立展示。排名只使用积分。
- 服务器完成规则校验、AI 行动和结果确认；终局与积分在同一 SQLite 事务中提交，以对局 ID 和账号去重。断网重试、重复点击、重启不会重复加分；AI 计算失败不会提交半步或自动降低难度。
- 榜单只向已登录玩家返回昵称和汇总成绩，不返回账号 ID 或棋谱。联机说明和隐私说明已更新。删除账号清除本人天梯记录并匿名化其他人的对手引用。关联两个已有成绩的账号时合并战绩，按计分局数加权平均人类实力分，不将两份 Elo 相加；删除两账号之间的自我对战记录。
- 每日限额是基础刷分抑制，不能证明防住多账号串通或真人使用外部辅助。没有引入设备指纹、实名数据或好友列表。

## 维护和发布

新增 `wx_ladder_stats` 和 `wx_ladder_results`，数据库 schema 从 3 升至 4，兼容读取并增量迁移旧 schema 1/2/3。结构不完整或未知版本会拒绝修改。维护工具支持备份/恢复 schema 4；恢复时保留最新身份、删除状态和天梯数据，不能复活已删除账号或重复结算。

旧版服务不认识 schema 4；正式启用前须准备支持 schema 4 的回滚代码，并保留停写备份。此前冻结的激活脚本仍指向其原版本，不能拿来直接激活本次候选。

本次在现有 `codex/wechat-minigame` 工作副本实现。主目录 `wechat/project` 是该工程的本机入口。新榜单依赖本次客户端和微信独立服务同时更新；源码与本地构建通过不表示服务器部署、微信上传、真机验收、提审或公开发布完成。
