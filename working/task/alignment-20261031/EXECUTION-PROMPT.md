4. **旧移动原生能力不能被新版网页覆盖。** 双存档键、revision/冲突、返回确认、后台取消/前台恢复、保存失败保留内存、文件导入导出、安全凭据与登录代际均须按宿主保留。原生ACK前不能提前恢复AI；凭据故障恢复必须明确极限，不能声称跨所有断电场景原子。
