## 七项改造

| 要求 | 当前实现 |
| --- | --- |
| 拓扑与普通棋盘对齐 | 共用认输、重置；取消独立“开始拓扑对局”。选择和高亮持久保存，重置应用下一局配置；选图不改变正在进行的棋局。 |
| 合并模式和起点编辑 | 移除经典、固定双起点、迁移起点三个独立模式按钮；自定义地图和起点进入同一图形编辑器。保留旧存档规则与增设起点能力。 |
| 拓扑不再另开设置页 | 三角形/六边形一行，菱形/拓扑棋盘一行；拓扑按钮只在原面板展开九个预设。随机地图、自定义棋盘直接放在棋盘面板。 |
| 多边界图形编辑 | 可新增、选择、删除边界、画孔洞、闭合/撤销、点选粘边及方向、放置/移除多起点；放大后可拖动画布。非法编辑保留原有效草稿，缺根或未闭合时禁止保存。 |
| 三行数字设置 | 悔棋、计时、提示各一行，左开关右数字；直接使用原生键盘，失焦校验，不弹输入窗。换页、滚动、后台和旧回调均有隔离。 |
| 实际行动顺序 | 颜色块显示序号，点选后拖动可改变完整轮转。快速纵滑用于滚动；横拖可直接排序。规则、AI、保存、悔棋、棋谱、共享房间、排位和贡献均保留顺序，颜色与起点归属不交换。 |
| 3D 优化 | 复用图像和深度缓冲、缓存颜色及共享点计算，暂停和界面重绘复用已绘制画面。四组固定场景像素逐字节相同，本机中位耗时降低约 15%–28%。 |

拓扑和拓扑联机支持 2–6 人；普通三种棋盘继续支持 2–15 人。普通棋盘仅修改起点时保持普通规则，不因进入统一编辑器就自动转换成拓扑。
