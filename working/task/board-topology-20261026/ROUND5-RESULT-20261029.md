## 理论及其工程含义

1. **三角面沿边粘合的商空间。** 保留规范顶点、边等价类、面和附着关系；同端点的不同边不能合并成一个邻接关系。它是有限二维面片/胞腔实现，不声称支持任意维 CW 复形。
2. **局部流形检查。** 内点 link 应为圆，边界点 link 应为区间；非六价顶点不自动等于非流形。对带边界三角曲面，按边重数计算度数，有

   `Σ内点(6−deg v) + Σ边界点(4−deg v) = 6χ`。

3. **模二链复形。** `C₂ → C₁ → C₀` 的两个边界矩阵由面边发生关系直接生成，逐面验证 `∂₁∂₂=0`，异或消元精确求秩：

   `β₀=V−r₁，β₁=E−r₁−r₂，β₂=F−r₂`。

   球面为 `(1,0,1)`，环面和克莱因瓶模二 Betti 数同为 `(1,2,1)`，双把手为 `(1,4,1)`；须另查可定向性。相对同调商掉真实边界胞腔，不能冒充普通同调。
4. **闭线与围地。** 仅对连通闭曲面上的单条嵌入圈使用“分离 iff 模二零同调”。零同调不等于可缩，双把手腰圈是反例。正式领土仍是规范图移去己方覆盖后、不含敌方且不触真实边界的分量，加上己方点线；不以同调或连续面积替换比分。
5. **永久连接充分证书。** 从己方根开始，真实逻辑路径的一端和所有内部点都已认证为永久己方节点时，才认证另一端。节点不可覆盖、路径不可切、端点保持连根，按认证层数归纳。`RootStability` 用依赖队列求最小闭包；这是充分条件，未认证并不表示可吃。
6. **双把手无自交 3D。** 平面区域挖两个互不接触的孔，前后两份沿全部边界粘合，Euler 示性数为 −2。只对渲染做重心细分：边界高度为 0、所有内部顶点/边中点/面中心高度严格正，前后分别映到 `(x,y,±h)`。零集恰为边界，两片只在指定粘边相遇；不增加规则落点。
7. **随机分布。** 不存在这里自动获得的“所有可三角剖分曲面均匀分布”。明确采用有限类别混合，再根据已验证的尺寸/人数支持集合条件归一化。有限搜索失败不等于数学不可实现；类别内有界重试失败会报告，不能偷偷换类。

理论正文与工程报告位于 `web/web前端/GuideTopologyChapters.js`，经现有生成器输出到中英文数学规则和 Code 文章。参考书、已知定理、项目推导与验证范围在正文区分。

## AI 结论的范围

- 永久根证书有规则内充分性证明；普通路线的战术复核只检查有限候选与下一真实行动方的直接切断/PASS，不是全树安全证明。
- 一条合作 PASS 的可达围困棋谱证明围困特征能进入真实局面，不证明强制围困。
- 微型三人局完成深度 6 的样本不代表所有盘面都能在约 3 秒完成该深度。不可抢占的同步步骤由主线程看门狗终止，执行前重新核验合法候选；不是所有设备严格 3 秒保证。
- 两局小盘同预算对照为一负一平，不能推出总体棋力提高。拓扑 AI 仍标“练习模式/棋力未评测”，不捏造榜单评级。
- 没有新模型训练、权重晋级、正式棋力评测、真实双客户端联机或微信/手机包验收。已有平台工作不会因本地 Web 测试通过自动同步。
