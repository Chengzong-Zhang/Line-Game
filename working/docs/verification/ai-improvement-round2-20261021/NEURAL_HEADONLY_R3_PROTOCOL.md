本轮预先固定两条 Research 路线：`padded-cnn-transfer-v1-seed2026092203`、`grid-gnn-transfer-v1-seed2026092202`。训练从各自 distill-v1 暖启动，采用新终局 rollout 标签、策略头更新与锚定约束；骨干、value 和独立 PASS 头冻结，训练与数值核验由独立训练协议/收据记录。其他 15 个双人模型本轮不新增更新。它是新的应用后训练实验，不是原强化学习优化器续训。

## 固定阶段与开发选择

每路线 40/80/120 次更新三个候选，ID 为父 ID 加 `-terminal-head-r3-s040`、`-s080`、`-s120`。候选 manifest 在 `local_artifacts/neural-terminal-headonly-r3-20261021/training/candidate-manifest.json`。比较基线始终是相应当前网页原始父权重，暖启动权重另在来源字段记录。

开发配置 `web/tools/configs/neural-headonly-r3-dev.json`：每阶段尺寸 5/7/9 各两个全新前缀，每前缀换色，共每阶段 12 局，六阶段合计 72 局。只在全部候选完成独立核验后选择：每路线选择平均对局得分最高的完整阶段；并列选择较早阶段。含截断阶段不合格；若某路线三个阶段均不完整，保留该路线失败状态，不用其他路线替补家族。选择结果及输入/输出 manifest 哈希写入单独不可覆盖的收据。

## 全新最终确认

固定两个入选候选、同一 PUCT-16 与 c_puct 1.5；尺寸 5/7/9 各十个新前缀，每前缀换色，共每路线 60 局，总 120 局。种子空间为 `neural-terminal-headonly-r3-20261021-FINAL-v1`，与训练、开发和先前 420 局不同。前缀 4 步，400 步或累计 120 秒推理仍未自然终局则截断，不造胜负。

各路线晋级条件同时满足：60 局全自然终局、均分至少 0.55、每尺寸至少 0.45、30 个换色前缀簇的非零符号做单侧二项边界尾检验，经固定两项 Holm step-down、FWER 0.05 后拒绝。每簇是两次换色得分平均减 0.5，胜/平/负得分为 1/0.5/0。截断路线按 p=1 保留在两项家族且不晋级。

检验假设独立前缀簇，联合零假设为各固定尺寸/先手层的非零符号正概率不超过 0.5；边界全为 0.5 时精确，较小概率时保守。它不是平均得分的检验，也不证明每尺寸都变强。模型间共享前缀，Holm 不要求模型间独立。描述性 95% 区间用按尺寸分层整簇 bootstrap 10,000 次；基础 seed 2026102191 与各模型 ID 的 SHA-256 前八位按位异或产生实际 seed。区间不作多重校正，不参与晋级门。

先要求原 arena v2 的独立完整回放/面积/全汇总字段核验 PASS，再独立重算晋级统计。Research PUCT 的动作契约允许主动 PASS，规则原型的 `skipTurn` 是合法性真源；不附加“有落点不得 PASS”的错误限制。每步策略只按原 verifier 的首/中探针检查，不声称所有神经策略步骤被重算。

## 可靠性与交付边界

复用已验证恢复的冻结 arena v2/supervisor；每步保存，不重跑已完成局。每个新 run root 独立监督，正常让出 300 秒、硬限 330 秒，异常最多 3 次、无进展最多 3 次。DEV/FINAL及核验的总预算预定 1800 秒，成本若超限保留未完成状态，不根据成绩延长或提前停止。训练/数据/核验的其他阶段按训练协议分别控制。

只有完整验证后才考虑本地网页接入，且改善范围限于实测 5/7/9、对相应父模型和指定预算。不得外推到大盘、所有对手或人类对局。不部署服务器或小程序。网页实际时延与 Worker 集成另行检查，不能用 Node 推理代替。
