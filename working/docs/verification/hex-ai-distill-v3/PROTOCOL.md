# Hex v3：v1 锚定的一轮回应蒸馏

本候选用于 4/5/6 人六边形 territory-v2。所有新文件独立于 v2；不修改共享引擎、v1/v2、默认 loader 或服务器。旧 v2 FINAL 仅作诊断，不作为新未见评估。

## 数据与目标

从 v1 开始，使用全新随机前缀。尺寸 5/7、人数 4/5/6 和各起手席位共有 30 条采样轨迹，每条最多 48 步，于第 12/24/48 步抽样，最多 90 个标签。前 8 步随机合法动作，之后按 v1 贪心行动。采样轨迹不是完整训练胜局，不声称它们完成了终局评估。

每个样本保留完整 Superko 历史；teacher 从 v1 第一选择、启发式第一选择及其余 v1 排序组成最多 3 个不同合法候选，分别实际走子并模拟至多一轮 v1 对手回应。按原引擎离散 area 为主的现有 utility（终局使用真实胜者份额）评分，以温度 200 转为目标概率。teacher 改动必须完整恢复原状态。

保留原 16 维线性特征及网页贪心推理形式。优化分组等权的交叉熵加 0.1 倍固定 v1 KL；Adam 学习率 0.03、梯度范数上限 0.5，保存 8/24/60 步三个候选。teacher 的非终局 utility 只是训练启发式，不能替代终局胜负。

## 选择与新 FINAL

新开发集：边长 5、人数 4/5/6、全部起手席位；每前缀一个 v1 对照和每阶段 single/multi，共 105 局真实终局。按平均配对胜者份额选择阶段，平局按 v1 KL、阶段序号。选择后冻结候选。

新 FINAL：全新 namespace `hex-v3-round-FINAL-20261021-unopened-r1`；5/7、4/5/6、所有起手席位，共 30 个前缀簇、90 局。单个和多个候选席位共享对照，簇是 bootstrap 单位。原门槛不变：平均提升至少 0.04，95% 下界 > 0，各尺寸与人数 ≥ −0.05，single/multi 均非负，所有对局真实终局。单局最多 3000 动作、90 秒，截断不得算胜负或晋级。FINAL 不用于选阶段。

## 预算与可靠性

校准 6 个 5/7×4/5/6 中局：一轮 3 候选 teacher 约 0.09–0.34 秒；90 标签预计约 31 秒纯 teacher 计算，另计轨迹生成和持久化。新训练启动时冻结全任务 3600 秒绝对 deadline（包含训练、开发、独立核验、FINAL 与其核验之间的时间），不可自动延长。训练单阶段最多 650 秒，训练核验 250 秒，FINAL 2200 秒，FINAL 核验 1000 秒；实际每项取剩余总预算与阶段上限的较小者，阶段上限不等于可相加预算。

每步动作、每个 teacher 样本、每次 Adam 更新和每局评估均持久保存；模型/配置/源码身份冻结。独立监督器、防重复锁、最多 3 次异常重启、连续 3 次无进展停止。放置 `PAUSE`/`STOP` 到相应 run root 即控制该项；预算用尽不自动恢复。所有原始轨迹和测试运行树保留本地。

恢复测试包括真实动作异常退出、样本提交后异常退出和幂等恢复、有限差分梯度、两步 Adam 的恢复一致性、暂停停止、重复启动和损坏拒绝。Adam 专用测试只用带明确标签的合成采样记账 fixture，不构成训练结果。正式新 FINAL 启动前还须用冻结候选完成一次新的真实中断恢复测试。

独立训练 verifier 重放采样轨迹、每个 teacher 标签、全部 Adam、开发对局及选择/输出。独立 FINAL verifier 重算每一步策略、历史、随机前缀、真实 area 和簇汇总。只有核验 PASS 和原晋级门全部通过才可建议后续集成；本次没有默认替换或部署。
