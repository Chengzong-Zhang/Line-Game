# 全部网页 AI 的本地后训练范围与证据边界

本轮授权来自用户“请把现在所有的 ai 模型进行进一步的后训练”，延续只在本地完成、
不上服务器、不同步小程序的要求。旧模型、已冻结训练与评估证据保留。

## 模型范围

共 19 条候选训练路线：

- 双人神经模型 12 个：Padded-CNN、Grid-GNN、Topology-GNN，每家族包含
  D14 legacy 版本与 transfer-v1 的 2026092201 / 2026092202 / 2026092203 三个 seed。
- 双人 model-free 模型 5 个：DQN、PPO、SAC、GAIL、GAN 当前网页版本。
- 三人模型 1 条：从上一轮 v2 候选继续得到 v3，同时对照当前默认 v1 和父模型 v2。
- 六边形多人模型 1 条：从 hex-player-v1 得到 v2，覆盖 4 / 5 / 6 人。

Minimax、Greedy、普通 MCTS 是没有学习权重的搜索算法，不把调整搜索参数称为后训练。
三人 v1 与 v2 是同一来源链；保留两者作为对照，不把历史版本另计为一次新训练。

## 双人：Web-compatible supervised policy distillation

所有 17 个模型分别从网页 F32 资产初始化，校验父资产 SHA-256 与张量清单。
这是新的策略蒸馏实验，重新初始化优化器和 RNG，不是旧 DQN/PPO/SAC 等算法实验的 resume。
旧检查点来源全部核对，但不用其大型 replay buffer 或不完整的恢复入口。

当前网页对五个 MLP 使用 ReLU；旧 Python 的部分模型使用 Tanh。
本轮以网页实际前向函数为准重建，明确记录这个差异，不静默修改旧模型推理语义。
研究网络复用现有结构，经 Python/Web 数值对照验证后使用。

数据使用 Web `territory-v2` 引擎生成，保留 Superko 历史及实际行动方。
尺寸 5–15，每尺寸 4 条训练轨迹和 2 条验证轨迹，共 66 条；按完整轨迹拆分，
每条最多 32 步，截断片段仅用于模仿，不作胜负数据。
教师为现有 Minimax depth 2（启发式根/回复候选上限 20），不是完整树最优解。
目标为温度 30 的教师分布，混入 5% 合法点均匀分布；行为为 65% 教师采样、
35% 随机合法点。数据配置与来源哈希由生成器绑定。

每个模型固定 100 次更新、batch 16、学习率 1e-4、父策略 KL 系数 0.1、
梯度裁剪 1。损失只监督合法落点策略；PASS / value 头参数保留，
共享骨干变化仍可能改变其输出，必须由网页实际推理评估。
不根据后续对战结果更换检查点或重调这一批候选。

独立应用筛查使用新种子、尺寸 5 / 7 / 9、每尺寸 2 个随机开局，
候选与父模型交换两次席位，每模型 12 局，共 204 局。
研究模型保持网页 PUCT-16 / c_puct 1.5；MLP 使用网页 `ModelFreeAI`。
每局最多 400 步或累计推理 120 秒，超限保留截断记录且不分配胜负。
这批小样本筛查不承担 17 模型多重比较后的晋级证明，**不会自动替换网页默认模型**。
尺寸 10–15 参加训练，但没有本轮完整对局强度评估，不能声称棋力提升。

## 多人：终局回报微调

三人和六边形使用独立新协议，以真实离散 area 的终局回报进行保守策略微调。
各自固定训练、开发、最终测试种子与预算，恢复测试通过后再启动。
三人当前 v1、上一轮未晋级 v2 与六边形 v1 均保留。
详见各自本轮配置与结果收据，不回写上一轮冻结协议。

## 运行与复核

所有长任务持久保存进度、模型、优化器及适用的 RNG / 在途动作；
使用独立隐藏监督进程、独占运行锁、有限重试及 PAUSE / STOP 文件。
提交中的临时写入隔离保存，已完成轨迹、模型或对局不重复执行。
对来源或校验损坏停止恢复，不修改 hash 强行继续。

双人数据及评估恢复测试均实际终止进程，比较恢复后的轨迹与无中断运行；
数据测试额外终止被监督 worker，验证监督者会从已提交进度恢复。
训练恢复测试须验证优化器、RNG 与候选逐张量一致。
