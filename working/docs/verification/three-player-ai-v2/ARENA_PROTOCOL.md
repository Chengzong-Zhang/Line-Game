# 三人 AI v2 独立应用评估协议

状态：预注册；尚未运行最终测试。该协议用于本地网页模型晋级，不构成普适棋力、跨尺寸泛化或科学正式实验的证明。v1、运行时规则和既有训练证据保持原样。

## 对象与对局

- 规则：Web `territory-v2`，三角棋盘、三人、尺寸 5 / 7 / 9，完整 Superko 历史。
- 候选：训练/开发阶段选定并冻结的唯一 16 维线性模型。基准：现有 `three-player-policy-v1.json`。两者均使用现有 `ThreePlayerAI.getTopMoves(engine, actor, 1)`，同一完整合法候选集合、特征、温度评分及确定性平分顺序。
- 每尺寸 × 每先手 × 两个独立随机开局，共 18 个前缀簇。每簇先均匀选择 3 个合法随机行动，再分别运行：1 局全 v1；3 局单候选对两 v1，候选轮换三席；3 局两候选对一 v1，v1 轮换三席。总计 126 局，其中混合阵容 108 局、配对对照 18 局。
- 独立命名域位于 `arena-final.config.json`；开局种子由 SHA-256 的前 32 位产生。它与训练、开发选型及吞吐校准命名域分离。最终测试只对已冻结的一份候选运行一次，结果不能用于选候选或调参数。
- 对手与候选都只在无合法步时跳过；引擎自动跳过按原规则执行。逐行动保存 actor、动作及完整前缀，恢复时重放所有历史。

## 指标与晋级

终局以离散 `area` 计算。所有最高分玩家共享 1 分：独胜 1，双平各 1/2，三平各 1/3。两候选阵容取两个候选席位共享胜分的平均，因此单/双阵容量纲相同。每局减去相同前缀全 v1 对照在相同席位的平均胜分，得到配对差值 Δ。

先对每个前缀簇的 6 个混合局求平均，再对 18 簇求平均。统计单位是随机前缀簇，不能把同簇不同席位/阵容的 108 局当作独立样本。置信区间使用按尺寸分层、整簇重采样的 10,000 次 percentile bootstrap，固定独立 bootstrap 种子。另报告阵容、尺寸、先手与焦点席位结果，以及平均两两排名得分差。有限簇数的区间仅用于本次应用门槛。

以下条件全部成立才可晋级：

1. 126 局全部到达真实终局，动作/策略/终局/来源独立复核通过；无截断、遗漏或重复。
2. 总体平均 Δ ≥ 0.04，簇 bootstrap 95% 区间下界 > 0。
3. 单候选和双候选阵容分别平均 Δ ≥ 0。
4. 每个尺寸平均 Δ ≥ −0.05。

失败时保留 v1，不用重新挑选候选或改变门槛后重复本次测试。可以报告“本次未达到预注册门槛”，不能把不显著解释为已证明等强。

## 预算与校准

正式评估每局最多 400 行动、60 秒决策计算，累计活动预算 1,800 秒。达到限制的非终局只能标 `TRUNCATED`，不产生胜负。独立 supervisor 负责进程硬超时与累计尝试预算；worker 在每个行动持久化边界检查时限，单次同步推理不能在 JavaScript 主线程内抢占。

先用 `arena-calibration.config.json` 的独立开局，在每尺寸运行一局全 v1，实测完整终局耗时；校准不读取候选强弱或最终种子。若吞吐预算需改变，应在最终评估启动前以新配置明确冻结，不能查看最终结果后修改。

## 运行、恢复和复核

```powershell
node web/tools/evaluate-three-player-ai.mjs --candidate <frozen-model.json> --config docs/verification/three-player-ai-v2/arena-final.config.json --run-root local_artifacts/<unique-final-run> --max-seconds 120
node web/tools/verify-three-player-arena.mjs --run-root local_artifacts/<unique-final-run>
```

`identity.json` 绑定源码、配置、模型 SHA-256；Web 规则/AI 源码复制到运行目录后冻结，后续实时工作区修改不会改变该运行的规则。worker / verifier / 公共评估代码发生修改、冻结源/模型或配置损坏时拒绝恢复。

每局 `games/<stable-id>.json` 原子提交并带完整性摘要；`active-game.json` 每次行动保存，`checkpoint.json` 记录已完成局与累计活动时间。已完成局不重跑；局提交后索引前退出可从局文件重建索引。未完成临时文件移入 `interrupted/` 保留证据。读取失败、完整性不符或身份不符停止，不删除证据后重来。

`PAUSE` / `STOP` 文件控制安全边界停止；暂停/停止文件存在时 supervisor 不重新拉起。回环端口独占租约防重复，操作系统在进程退出时释放租约。退出码：0 完成；75 预算切片/暂停/停止；78 身份/数据/配置错误或总预算耗尽；1 可有限重试异常。`progress.json.progress_units` 是已原子提交的局数。

独立 verifier 重建随机前缀、逐步核对策略选点和合法性，重新计算终局离散面积、共享胜分和聚合指标，核对完整来源链。`--allow-incomplete` 只用于恢复演练，不能作为完成或晋级证明。

原始棋谱、活动检查点与执行树保留在 `local_artifacts/`；协议、紧凑汇总、SHA-256 与最终验证收据可进入版本控制。
