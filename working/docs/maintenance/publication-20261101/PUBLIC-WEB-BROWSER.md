# 公开网页浏览器核验

2026-11-01，Web 原子激活后，通过内置 Chromium 实际打开 `https://lifelinegame.cn/`，标题为“生命线策略棋”，主界面与 Canvas 正常呈现。该来源已有本地终局存档，页面显示自动恢复；本次没有重置或覆盖该对局。

从真实 UI 打开指南舱 → 规则 → 抽象版。当前正文包含完整状态、离散计分与显示面积区别、拓扑第四章及适用边界；展开“文章目录 · 4”后四章按钮可见。临时视口390×844，DOM显示页面 clientWidth=390、scrollWidth=390。测试后恢复默认视口。

证据：[公开网页手机指南](public-web-guide-phone.jpg)。此截图是 Web 发布核验材料，不满足用户所贴微信备案必须使用微信小游戏截图的要求。

本次观察确认外网浏览器的实际启动、恢复提示和指南阅读；没有在公开入口另开真人对局、真实账号跨端对战或微信设备验收。最终候选在本机已完成的 Canvas/PASS/导入导出闭环仍见前轮 [浏览器记录](../completion-20261101/BROWSER-ACCEPTANCE.md)，不将两类环境合并冒称全部公网行为通过。
