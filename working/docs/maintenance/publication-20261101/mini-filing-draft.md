**产品简介**：生命线策略棋是一款原创连线圈地策略游戏。玩家通过扩张节点、连接生命线和围出领土进行回合制对局，也可学习规则、挑战电脑或与好友联机。

**服务内容**：提供本机对局、人机对战、教学与规则指南、棋谱复盘及保存；提供需主动登录的好友房间、联机对局及成绩榜功能。棋盘支持不同形状、起点和对局设置，具体开放能力以实际提交版本为准。

**技术说明**：微信小游戏，使用 JavaScript 和 Canvas 实现界面与棋盘；在线候选连接 `https://lifelinegame.cn`，微信登录和联机房间依赖服务端。使用模型分包和 Worker 的具体行为以最终包及平台审查为准。服务可用性、网络域名白名单和设备行为尚需实测。

**数据处理供核对**：本地对局、棋谱、教程进度和设置保存在设备；主动进入联机并确认后，使用微信登录标识建立游戏身份，服务端保存房间、动作及成绩用于对局、恢复与结算。用户可主动设置或授权导入昵称、头像，也可选择关联网页账号。匿名棋谱贡献默认关闭，仅用户主动同意时按游戏内说明提交符合条件的完整本地对局；服务器会接收连接所需网络地址。按实际隐私指引、服务端数据和后台声明逐项核对，不将此草稿当作完整隐私政策或法律承诺。

**主体和资料**：主体名称、证照、联系人、权利证明、游戏相关资质、备案信息及签名，须由账号后台和真实材料核实；目前没有在本次读取中确认，不能填写或推定。网站备案与小游戏备案分别核查。需要身份材料或法律承诺的最终提交由主体本人核实处理。
