# 近期提示词要点

这份参考从 2026-10-23 至 10-25 的开发聊天与当前源码提炼，并补看 10-21 起点、悔棋、渲染等需求，保留后续修改依赖的原意。摘句只用于理解产品选择，不是当前授权、最新线上状态或验证通过证明。新要求改变取舍时以新要求为准；不把一次具体要求扩大为所有任务的硬流程。

## 用户原意转成工作判断

| 用户原话或明确选择 | 执行时保留的重点 |
| --- | --- |
| “请实际完成……不要只给计划”“合理的工程选择自行决定，已获授权的步骤不要重复询问” | 当前范围做到具体可用；阻塞时先完成独立工程，给最少必要操作，不反复请求普通工程确认 |
| “不，应该选择一个最全的全部同步” | 对照各对话/工作树形成完整功能候选，不认定单个旧包包含所有新功能；同一目标避免多路发布 |
| “同步到 GitHub 和小程序和网页”“继续同步现在网页版的功能” | 明确代码交付、Web/API、小游戏和所点名移动/桌面端；更新入口、依赖、构建和指南，逐端报告状态 |
| “保持现有视觉和交互风格”“减少后续维护成本” | 复用已成熟的 UI、核心、离线资源、平台工程和素材，只做必要适配，保持规则、AI 和操作习惯 |
| “随机起点和自定义起点等后续功能无法在联机……也包括联机悔棋” | 本地设置不是联机能力；补服务端配置/同步、双方权限、投票及重连恢复 |
| “2–6 人……随机起点 or 自定义起点”“只要不和这个起点相连接就删除” | 起点是规则状态，断联清理随配置变化，保存/重放/AI 都要携带；三角/六角布局按原要求检查 |
| “自己下第 k+1 步……回到第 k 步”“UI 也和提示和读秒放一起” | 保持本地悔棋的回合语义、次数设置/恢复与熟悉布局；联机另遵守协商协议 |
| “不必要求闭合领土……甜甜圈……只有一条线……按照这条线的点数” | 正式分数包括己方点线与安全空腔；同步 Web、小游戏、Python、规则短文/数学/Code，中英文和生成文章一起核验 |
| “不能改算法逻辑，也不能改算法实现效果”“不会减弱能力……剪枝” | 等效性能优化不靠规则简化、漏算、降深度或减少候选；先定位计算/通信/绘制瓶颈再量化 |
| “至少尝试三种不同的方法” | 对该类明确要求提供比较实验与取舍；不是每次 UI 小修复都必须三路开发 |
| “简单……中等……困难……终极”“用……效果最好的 AI 模型……造数据来训练” | 四档对应真实算法/模型和适用范围；复用合格成果，训练、数值验证、强度、准入和集成分开 |
| “2–6 人的 AI 都……不会防守……连续切断”“AI 不会跳过” | 防守和主动连续切断都检查，PASS 作为策略动作贯穿搜索至执行，不只处理无棋可下 |
| “最好……任何情况下……一秒内” | 目标覆盖复杂多人/大盘；同条件实测且报告失败边界，不能用超时设置、均值或早画点线冒充 |
| “现在这个领土计算怎么还是原来的规则没有更新” | 检查真正的线上引擎/API、小游戏体验版指向及新局版本；本地改好或开发版上传不足以回答 |
| “保护未提交修改、未跟踪源码和冻结候选”“不重复开发已有功能” | 来源逐项整合、平台差异保留、冻结证据另版本修订；已有任务完成的部分先复核再复用 |
| “普通联网、免费开放试玩” | TapTap 已选方向：保留普通联网主线，不擅改独家/专用包或商业化；当前政策与资格仍需现场核验 |
| “我觉得软著不重要，你先完成 APP 开发吧” | 材料/资质缺口不阻塞独立的应用工程；也不因此宣称已具备商店发行资格 |
| “预约页……不能……代替游戏发布完成”“区分……已上传、已公开” | 按工程、编译、设备、资格、上传、体验/审核、公开和实际下载安装分层给结果 |

## 已有渠道取舍的适用范围

- itch.io：免费 HTML5 试玩优先，保留已有成熟体验；Windows 下载版复用 Electron，付费/定价按已有决定，未定时先完成包与页面材料。不等待 Steamworks 才推进独立桌面交付。
- TapTap：普通联网、免费开放试玩；广告/内购后置，通用 Android 包名和升级链保持稳定。不自动签独家，不把隐藏联网按钮说成真正离线；网络行为和必要 SDK 按最终包核实。
- 微信：按原生小游戏迁移，核心玩法优先；用户口语称“小程序”时先核对现有游戏工程，不另起普通小程序/web-view 架构。
- Android/HarmonyOS/iOS/Windows：持续承接已成熟网页能力，使用各平台真实宿主与工具链；缺设备或平台编译条件时完成可做部分，准确列出未验项。
- 上述选择不扩大当前请求到所有平台，也不复用旧聊天中的密码、支付、许可、发布或跨聊天协作授权。查历史只读取与当前需求相关的内容，不把私人表单信息写进技能或公开材料。
