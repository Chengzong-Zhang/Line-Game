# 仓库、指南舱与技能维护

用于 GitHub/README、目录整理、指南阅读界面或本技能更新。这里记录工作方法，不存实时发布状态；现场源码、AGENTS 和本轮要求优先。

## 仓库入口和目录

- 同时查看默认分支、当前工作区和平台工作树。README 的旧能力、日期和历史 PASS 不能证明当前产品；维护功能说明时核对真正入口与人数/棋盘/规则/AI 范围。
- 同一任务有多个 checkout 时，所有读取、修改和构建显式指定绝对目标；先核对基线文件 SHA，再移植窄增量。默认 cwd 可能仍是旧主目录，不能把从它生成的候选称作另一工作树的后继。替换组件块时保留相邻辅助函数、导入与新能力，并检查完整差量，语法通过不足以证明来源正确。
- 根 README 服务玩家和开发者：试玩、规则、可核实的能力、最短本地启动、源码与文档导航。详细渠道收据放正式文档，不把安装候选、体验版或商店状态混成“已发布”。
- 正式文档与任务位于 `working/docs/`、`working/task/`。旧 `docs/` 等可能是兼容 junction；`platform/*/project`、`mobile/*/project`、`wechat/project` 通向独立工作树。修改前定位实际实体，不能递归移动或清理这些入口。
- `working/tools/setup-layout.ps1 -Check` 仅检查本机导航。可选目标显示 `UNAVAILABLE` 时即使退出 0 也不表示平台可用；普通模式创建空目录不等于恢复内容。
- 新临时脚本、包和日志进入 `working/tmp/` 或 `working/local_artifacts/`。不能按文件夹名称、体积或 prunable 标记判断旧实验/工作树可删除。冻结资料不改路径；整理优先导航与归属。
- 本地文档链接通过后，检查链接目标在将交付的 Git 提交中是否存在，避免本机未跟踪源码掩盖 GitHub 断链。推送前只暂存本任务内容，检查凭据、大文件和相关验证。

## 指南唯一来源与可读性

先查实际 `GuideContent.js`、`GuideArticleFormat.js`、`GuideMathChapters.js`、`GuideImplementation*.js`、`GuideTopologyChapters.js` 及 `GuideReaderModal`；路径不存在时定向搜索，不照旧地图新造文件。

规则简版/战争版、数学文章、Code 报告、中英文、嵌入内容及外部 Markdown 需要一致。生成文章使用 `web/tools/sync-implementation-guides.mjs` 与 `--check`；不能只改生成结果。区分真实规则、已知定理、项目推导和未验结论。常规 v3 与拓扑计分分开，AI 估值不称胜率。

外部文章与内嵌回退都属于活跃产品内容。验证成功请求之外，还检查非 200、断网、正文读取失败及空正文；切语言的迟到响应不得覆盖当前内容。历史长文保留日期与适用规则，不能用旧快照覆盖当前说明。上界不写成紧确率，PASS/认输不套用落子才成立的历史增长论证。

当前项目的拓扑理论在数学文章第四章、实现说明在 Code 第四章；沿现场唯一来源维护。旧独立入口转对应锚点，避免重复卡片/正文。章节目录需从最终渲染标题获得稳定 ID，不依赖标题文本硬编码；切文章/语言后更新，保留旧锚点与返回行为。

阅读 UI 保留成熟视觉，针对真实问题调整行宽、字号/行高、标题、段落、列表、对比度和目录。手机上目录可折叠，长公式/代码只在局部容器滚动，标题不被固定控件遮挡；键盘可以打开目录和跳转章节。指南和搜索不得修改当前对局。

内容生成与现有指南检查后，用实际浏览器打开文章、切语言、点目录、返回并检查长公式/代码与窄屏。Node、HTTP 200 和源码样式检查均不能称视觉验收；环境受限时记录明确未验范围。

## 技能源与安装

仓库维护副本建议为 `working/skills/lifeline-dev/`，保留完整 references 和现有 agents 元数据。用户将技能口语称 lifelinegame 时，优先核对现有 `lifeline-dev`，不默认复制一个容易漂移的新技能。

修改保持精简：常用决策放 SKILL，按任务读取的流程放 references。更新路径/能力时不用当天发布 ID 替代现场发现；新经验只在对应任务条件下生效，不增加自动推送/上传/训练权限。

运行 skill-creator 的 `quick_validate.py`，检查 Markdown 引用和具体行为场景。验证后只同步本技能的明确文件到已安装路径，保留其他技能和现有授权/元数据。同步前后哈希与实际路径写入本次收据；权限阻塞时给已验证副本及确切安装步骤，不能称已安装。

仓库副本完整但不代表模型下一轮已加载新文本；说明文件安装结果即可，不伪造运行时热加载。
