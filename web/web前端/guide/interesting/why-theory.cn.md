# LIFELINE 理论：实现形式化、组合博弈、复杂度与强化学习

> 对象：当前 Web 版 GameEngine.js 与 AIEngine.js。
> 规则快照：2026-08-26。
> 复杂度章节中的 \(n\) 指解除代码中棋盘大小上限后的广义规则族；实际引擎只接受 \(5\le n\le15\)，当前 Web 设置界面提供 \(6\le n\le15\)。

## 摘要

LIFELINE 是有限、确定、完全信息的顺序图博弈，但当前实现并不只是“在三角格点上放节点”。一个忠实状态必须同时记录物理格点、各方显式逻辑边、当前玩家、认输集合、连续跳过数、终局标志与 Superko 历史。显式边直接参与攻击后的根连通 BFS、边恢复和 Superko 序列化；它不是可从当前节点唯一重建的显示缓存。

令玩家数 \(m\in\{2,3\}\)。边长为 \(n\) 的棋盘有

\[
N(n)=\frac{n(n+1)}2=\Theta(n^2)
\]

个物理格点，以及

\[
Q(n)=3\sum_{\ell=1}^{n}\binom{\ell}{2}
=\frac{n^3-n}{2}
=\Theta(n^3)
\]

个潜在共轴端点对。当前实现中，一个 Superko 序列化位置的安全上界为

\[
P_m(n)
\le
m\,2^m(2m+1)^{N(n)}(m+1)^{Q(n)}
=2^{O(n^3)}.
\]

因此：

- 当前实现不能使用 \(2\cdot3^{N(n)}\) 作为等价状态上界；
- 成功落子数至多 \(P_m(n)-1\)；
- 完整对局深度至多 \(m(P_m(n)+m-1)=2^{O(n^3)}\)；
- 分支因子至多 \(N(n)+2=O(n^2)\)；
- 朴素博弈树至多为 \(2^{2^{O(n^3)}}\)。

Superko 并不使每种行动都增加历史大小：主动跳过、自动跳过和认输都不写入历史。但完整增广游戏仍是 DAG。令 \(H\) 为历史哈希集合、\(R\) 为认输集合、\(c\) 为连续跳过数，则

\[
\rho(q)=(m+1)^2|H|+(m+1)|R|+c
\]

在每条合法转移上严格增加。

复杂度类必须作用于一个广义决策问题，而不是作用于“这个游戏”四个字。当前可证明的是：显式位置版的广义双人强制获胜问题属于 EXPSPACE，也有双指数时间上界；尚无到当前完整规则的 NP-hard、PSPACE-hard、EXPTIME-hard 或 EXPSPACE-hard 归约。三点限制可严格承载一个 PSPACE-complete 的抽象 Col 变体，当前引擎中也存在可达的两步“计分领先翻转 + 同色相邻互斥”见证，但动作隔离、长程连线隔离与可组合计分尚未闭合。搜索空间巨大不等于 NP-hard。

关于策略窃取，当前能够证明的也比旧说法更精确：三点限制使“额外一个己方节点永远无害”这一单调性前提为假，所以经典的额外棋子型策略窃取证明不能直接使用；主动 Pass 又使玩家不被规则强迫落子。不过当前引擎确实存在最大压力 \(Z=2\) 的可达状态：Pass 获胜而唯一 Place 在最优应对下失败。它证明了严格的 Place-vs-Pass 动作价值反转；若只在该给定状态禁用 Pass，它是 Zugzwang，但这条到达历史使用了主动 Pass，尚未证明 no-Pass 变体从标准初局可达 Zugzwang，也尚未证明“额外己方节点降低整个可比状态的 Minimax 值”。

Superko 还能产生一种与额外棋子非单调性不同的、真正的**历史分叉**。本文给出两条从标准初局可达的 \(n=6\) 历史：它们到达完全相同的格点、显式边、行动方、跳过数与计分规则核，却因 \(H\) 不同，使同一攻击落子在一局合法、在另一局只因命中旧键而非法。另一个八步回环见证证明去掉历史的位置投影确实含环，而 Superko 恰好截断闭环边。精确 Minimax 进一步表明，已找到的回环见证只把 White 的制胜首着从三个缩为两个，双方根值仍同为 \(+1\)。所以已经证明的是“历史盲的逐动作复制不具有普遍合法性”和“Superko 可迫使制胜策略绕行”，尚未证明 Superko 导致胜负值反转，也尚未证明所有历史感知的策略窃取失效。

从组合博弈论看，固定棋盘上的基本对象是增广状态上的有限 partizan scoring-play short game，而不是物理盘面上的 nimber。本文进一步定义了 Place 相对 Pass 的节拍收益、决策结果跨度、同核异史的动作掩码距离以及一个严格分段线性的“落子税谱”；它们是可计算的 temperature-like 指标，但不是未经证明的 Conway temperature。二人胜负效用下 Resign 被始终合法的 Pass 弱支配，可从最优求值中删除；已有最大 Pass-pressure 反例则证明 Pass 本身绝不能删除。

从强化学习看，忠实环境是以完整 \(q=(\sigma,\mathbf E,\tau,R,c,H,z)\) 为内部状态的确定性 Markov game。同核异史反例严格证明，只看当前格点与边的前馈观测不是 Markov，甚至合法动作掩码都不能唯一确定。本文据此给出动作/Normalize/奖励契约、历史感知状态键、按真实行动方备份的规则、关系 GNN 与 line-hypernode 表示、势函数奖励塑形、AlphaZero/PPO/PSRO 的适用边界，以及由现有可达反例组成的可证伪评测套件。当前尚未执行正式强化学习训练；这些是由实现与定理约束出的研究设计。

当前领土算法还不保持换色镜像公平。一个 10 手可达状态在原局双 Pass 后为 DRAW，镜像换色局双 Pass 后却为 BLACK 胜。根因是贪心收紧依赖闭合轮廓的数组起点、方向和同目标候选的枚举先后。本文给出玩家基点规范坐标、双方向取紧和轨道求和三种可严格证明恢复等变的计分定义。

## 2. 当前规则的完整形式化

### 2.1 棋盘、邻接与玩家

格点集为

\[
\mathcal V_n
=
\{(x,y)\in\mathbb Z_{\ge0}^2:x+y\le n-1\}.
\]

六个单位邻接方向为

\[
D=\{(1,0),(-1,0),(0,1),(0,-1),(1,-1),(-1,1)\}.
\]

若 \(v-u\in D\)，记 \(u\sim v\)。两个不同格点共轴，当且仅当

\[
x_u=x_v,\qquad
y_u=y_v,\qquad\text{或}\qquad
x_u+y_u=x_v+y_v.
\]

玩家的固定轮换顺序为

\[
\mathcal C_2=(B,W),\qquad
\mathcal C_3=(B,W,P).
\]

二人模式基点为

\[
r_B=(0,0),\qquad r_W=(n-1,0).
\]

三人模式基点为

\[
r_B=(0,0),\qquad
r_W=(0,n-1),\qquad
r_P=(n-1,0).
\]

起手方可以配置；默认是 \(B\)。轮换时跳过已经认输的玩家。

### 2.2 物理层与显式边层

每名玩家 \(a\in\mathcal C_m\) 有节点态 \(a_N\) 与线点态 \(a_L\)。物理棋盘标记为

\[
\sigma:\mathcal V_n\to
\{\emptyset\}\cup\{a_N,a_L:a\in\mathcal C_m\}.
\]

所以每格有 \(2m+1\) 种物理状态：二人模式 5 态，三人模式 7 态。

令

\[
\mathcal U_n
=
\{\{u,v\}:u,v\in\mathcal V_n,\ u\ne v,\ u,v\text{ 共轴}\}
\]

为所有潜在逻辑边。每方还有一个显式边集

\[
E_a\subseteq\mathcal U_n.
\]

当前实现中的 \(E_a\) 是规则状态，而不是可忽略缓存，原因有三：

1. 攻击后从基点出发的 BFS 只沿 \(E_a\) 行走；
2. 攻击会删除、清理并有条件恢复这些边；
3. Superko 序列化包含每一方的显式边列表。

格点线态与边集没有“双向唯一决定”关系。新增节点最初会连接所有无遮挡的共轴己方节点；攻击后的爬行重连却只补每条射线上遇到的第一个己方节点，而且边恢复只恢复攻击前已经存在的边。因此，相同格点标记配上不同显式边集，在当前程序中可能具有不同合法后继，必须视为不同位置。

### 2.3 忠实的规则状态

忽略可重新计算的显示缓存后，完整状态写成

\[
q=
(\sigma,\mathbf E,\tau,R,c,H,z),
\]

其中：

- \(\mathbf E=(E_a)_{a\in\mathcal C_m}\)；
- \(\tau\in\mathcal C_m\) 是当前玩家；
- \(R\subseteq\mathcal C_m\) 是认输集合；
- \(c\in\{0,\ldots,m\}\) 是 consecutiveSkips；
- \(H\) 是实现所记录的 Superko 序列化位置集合；
- \(z\in\{0,1\}\) 表示是否终局。

turnCount 不影响合法性、转移或胜负。在由公开规则接口正常产生的状态中，

\[
\text{turnCount}=(|H|-1)+|R|,
\]

因为初始历史已有一个元素，成功落子同时增加历史与回合数，认输只增加回合数，跳过两者都不增加。

cachedTerritories、polygon 与 displayArea 都可由当前物理棋盘重新计算，因此不是最小规则状态。若要逐字段复现 UI 快照，可以把它们加入工程状态，但不能因此改变博弈的数学状态数口径。

### 2.4 对手、保护区与认输者遗留物

代码中的对手集合是

\[
\operatorname{Opp}(a)=\mathcal C_m\setminus\{a\},
\]

它不排除已认输玩家。因此，认输不会删除该玩家的节点、线点或边；这些棋子仍会阻挡连线、参与其他玩家的敌方集合，并继续产生基点保护区。

玩家 \(a\) 的禁入保护区为

\[
Z_a
=
\bigcup_{b\in\operatorname{Opp}(a)}
\operatorname{Adj}(r_b).
\]

任何落在 \(Z_a\) 的落子都非法，攻击落子也不例外。

### 2.5 连线条件

记 \(L[u,v]\) 为两个共轴格点之间包含端点的离散线段，\(L^\circ[u,v]\) 为内部点。对玩家 \(a\)，两个己方节点 \(u,v\) 可连接，当且仅当：

1. \(u,v\) 共轴；
2. 每个内部点都不是任何对手的节点或线点：

\[
\forall w\in L^\circ[u,v],\quad
\sigma(w)\notin
\{b_N,b_L:b\ne a\}.
\]

己方节点和己方线点不阻挡连线。一次新落子必须至少连接一个既有己方节点，否则落子失败。

### 2.6 三点限制的真实规则

设落子前玩家 \(a\) 的节点集为 \(N_a\)，候选点为 \(v\)，并令

\[
A_a(v)=N_a\cap\operatorname{Adj}(v).
\]

对非攻击落子，三点检查通过当且仅当

\[
|A_a(v)|=0,
\]

或

\[
A_a(v)=\{u\}
\quad\text{且}\quad
N_a\cap\operatorname{Adj}(u)=\emptyset.
\]

所以它不只是禁止一个最小三角形。候选点相邻两个己方节点时非法；即使只相邻一个己方节点，只要该节点已经单位邻接另一个己方节点也非法。这会禁止三节点链、V 形和三角形。

只有覆盖对手线点的攻击落子豁免三点限制。把己方线点升级成节点仍要通过三点检查。

### 2.7 三种玩家行动

在非终局决策状态中，当前玩家的动作集合为

\[
\mathcal A(q)
=
\{\operatorname{Place}(v):v\in\mathcal L(q)\}
\cup\{\operatorname{Pass},\operatorname{Resign}\}.
\]

这里 \(\mathcal L(q)\) 是全部合法落点。自动跳过是确定性的规则归一化，不是玩家选择分支。

底层 resignPlayer(player) 接口允许指定任意尚未认输玩家；正式博弈模型把它收紧为“当前玩家只能认输自己”，这与正常 UI 的权限语义一致。若把宽松的底层 API 也当作规则动作，分支因子只需把后文的 \(N+2\) 放宽为 \(N+m+1\)。

## 3. 落子转移

### 3.1 初始可占条件

候选点 \(v\) 的原状态必须满足

\[
\sigma(v)\in
\{\emptyset\}\cup\{b_L:b\in\mathcal C_m\}.
\]

因此允许：

- 在空点落子；
- 覆盖敌方线点并攻击；
- 把己方线点升级为己方节点。

任何玩家的节点都不能被直接覆盖。

令当前玩家为 \(a\)。一次 Place\((v)\) 还必须满足：

1. \(a\notin R\) 且 \(v\in\mathcal V_n\)；
2. \(v\notin Z_a\)；
3. 若 \(v\) 原来不是敌方线点，则通过三点检查；
4. 临时放置后至少可连接一个既有己方节点；
5. 完成攻击与重连后的新序列化位置不在 \(H\) 中。

### 3.2 新节点与初始新边

先执行

\[
\sigma(v)\leftarrow a_N.
\]

对每个既有己方节点 \(u\)，若 \(u,v\) 满足连线条件，则：

\[
E_a\leftarrow E_a\cup\{\{u,v\}\}.
\]

线段内部的空点写成 \(a_L\)，已有己方线点保持，己方节点保持节点。这个阶段连接所有符合条件的既有节点，不只连接每个方向最近的节点。

若没有建立任何连接，则把 \(v\) 恢复成原状态并拒绝落子。

### 3.3 攻击、断边与根连通删除

若 \(v\) 原来是玩家 \(b\ne a\) 的线点，则攻击所有者是 \(b\)，而不是“所有对手”。

首先删除 \(b\) 方所有物理投影已经不完整的显式边：

\[
E_b^{\mathrm{intact}}
=
\left\{
\{u,w\}\in E_b:
\forall x\in L[u,w],\
\sigma(x)\in\{b_N,b_L\}
\right\}.
\]

因为攻击点已变成 \(a_N\)，所有穿过该点的 \(b\) 方边都会同时断裂。

在逻辑图

\[
G_b=(N_b,E_b^{\mathrm{intact}})
\]

中，从固定基点 \(r_b\) 做 BFS。令可达节点集合为

\[
C_b=\operatorname{Reach}_{G_b}(r_b).
\]

存活的物理棋子集合为

\[
S_b
=
C_b
\cup
\bigcup_{\substack{\{u,w\}\in E_b^{\mathrm{intact}}\\u,w\in C_b}}
L[u,w].
\]

所有不在 \(S_b\) 中的 \(b_N\) 与 \(b_L\) 都被清空。这里的生死由显式 node-to-node 边图的根可达性决定，不是物理六邻接连通性。

随后引擎：

1. 保存攻击前的各方边集；
2. 清空被攻击方的边集并清理所有物理投影已断裂的边；
3. 只恢复攻击前已经存在、端点仍是同色节点且当前无遮挡的边；
4. 恢复边时只把空的中间点写成对应线点。

若本次确实清除了棋子，代码会尝试为所有玩家恢复合格的快照边；若没有清除任何棋子，只显式恢复落子方与被攻击方的快照边。之后才执行落子方的爬行重连。

所以结算不会把“当前所有无遮挡节点对”无条件重建为完整闭包。

### 3.4 爬行重连

攻击处理之后，引擎只对当前落子方执行六方向爬行重连。对每个己方节点和每条射线：

1. 遇到敌方节点或线点立即停止；
2. 遇到该方向第一个己方节点时，若尚无显式边，则新增该边并把路径上的空点写成己方线点；
3. 随即停止该射线。

这一历史相关的“恢复旧边 + 首节点爬行”过程正是显式边不能由节点唯一推导的原因。

### 3.5 实现型 Superko

实现使用确定性的 JSON 序列化字符串，而不是可能碰撞的短哈希。定义

\[
K(q)
=
\operatorname{Serialize}
\bigl(
\tau,\ R,\ \sigma|_{\sigma\ne\emptyset},\
(E_a)_{a\in\mathcal C_m}
\bigr).
\]

它包含：

- 下一位行棋方；
- 按固定玩家顺序排列的认输集合；
- 排序后的所有非空物理格点；
- 每方排序后的显式边列表。

它不包含连续跳过数、终局标志、turnCount 或领土缓存。

初始集合为

\[
H_0=\{K(q_0)\}.
\]

候选落子完成全部结算后，以“下一位未认输玩家”为 \(\tau'\) 计算 \(K'\)。若

\[
K'\in H,
\]

则回滚棋盘和全部显式边，落子非法；否则

\[
H\leftarrow H\cup\{K'\}.
\]

然后 turnCount 增加 1、连续跳过数重置为 0、切换玩家、执行自动跳过归一化并更新领土。

这是一种实现特有的、包含行动方、认输集合和显式拓扑的 situational-like Superko。它只记录初始位置和成功落子后的序列化位置；Pass 与 Resign 都不写入 \(H\)。

## 4. Pass、自动跳过、认输与终局

### 4.1 主动 Pass

在任意非终局状态，当前玩家都可以主动 Pass，即使仍有合法落点。其效果为

\[
c\leftarrow c+1.
\]

若

\[
c\ge|\mathcal C_m\setminus R|,
\]

则立即终局；否则切换到下一位未认输玩家，再执行自动跳过归一化。

主动 Pass 不修改棋盘、边、历史或 turnCount。

### 4.2 自动跳过与归一化

若当前玩家没有任何通过完整 Superko 检查的合法落点，引擎自动执行一次跳过：

\[
c\leftarrow c+1.
\]

达到剩余玩家数时终局；否则继续轮换并递归检查。已经认输的当前玩家只被轮换逻辑跨过，不构成选择分支。

可把这段确定性过程写成归一化算子

\[
\operatorname{Normalize}(q),
\]

它一直运行到：

- 找到一名尚未认输且至少有一个合法落点的当前玩家；或
- 进入终局。

若启用 Web 回合计时器，超时会由界面层调用同一个 Pass 流程。纯组合规则模型不记录真实时间；若要研究计时赛，必须把剩余时间加入状态。

### 4.3 Resign

当前玩家认输时：

\[
R\leftarrow R\cup\{\tau\},
\qquad
c\leftarrow0.
\]

turnCount 增加 1，但 \(H\) 不变。认输者的棋盘元素、显式边与保护区全部保留。

若剩余玩家数不超过 1，则终局；否则轮换到下一名未认输玩家并归一化。

### 4.4 终局与胜者

终局有两个来源：

\[
c\ge|\mathcal C_m\setminus R|
\]

的连续主动或自动跳过，或者

\[
|\mathcal C_m\setminus R|\le1
\]

的认输终局。

终局时只在未认输玩家中比较离散领土 area。唯一最大者获胜；最大值并列返回 DRAW。二人局一方认输后，唯一未认输者无条件获胜，不看面积。三人局第一人认输后继续，第二人认输后唯一剩余者立即获胜。

## 5. 领土与计分的算法语义

领土不是简单的几何多边形面积，而是一个确定的“物理轮廓—局部贪心收紧—边界泛洪”算法。

### 5.1 外轮廓

对玩家 \(a\)，取物理友方集合

\[
F_a=\{v:\sigma(v)\in\{a_N,a_L\}\}.
\]

显式边集不直接参与轮廓追踪。以 \(x\) 最小、再取 \(y\) 最小的友方格点为起点，使用固定顺时针方向序列和右手摸墙规则，在 \(F_a\) 的六邻接图上追踪至多 \(6|F_a|+10\) 步。得到的格点序列记为 \(P_0\)。若长度小于 3，领土为 0。

这个序列是实现定义的轮廓，不应未经证明就称为一般几何意义下的简单多边形。

### 5.2 覆盖算子

对任意轮廓序列 \(P\)，把出现过的格点作为墙：

\[
W(P)=\{v:v\text{ 出现在 }P\}.
\]

三角棋盘边界为

\[
\partial\mathcal V_n
=
\{(x,y):x=0\text{ 或 }y=0\text{ 或 }x+y=n-1\}.
\]

从所有不在墙上的边界点开始，在六邻接图 \(\mathcal V_n\setminus W(P)\) 上泛洪。定义

\[
\operatorname{Cov}(P)
=
\mathcal V_n\setminus
\operatorname{Flood}_{\mathcal V_n\setminus W(P)}
\bigl(\partial\mathcal V_n\setminus W(P)\bigr).
\]

离散面积为

\[
A(P)=|\operatorname{Cov}(P)|.
\]

墙点本身未被水淹，因此也计入 area。

### 5.3 贪心收紧

从 \(P_0\) 开始，引擎反复枚举轮廓顶点对，并在不经过任何敌方节点或敌方线点的单位格图上重建所有最短路径。只考虑比被替换弧段严格更短的路径，并构造两侧候选轮廓。

候选的选择目标是严格下降的字典序

\[
\bigl(|P|,A(P)\bigr):
\]

先缩短周长；同周长时再缩小离散覆盖面积。相同周长和面积不替换，枚举顺序决定完全相同目标值下保留哪一个候选。

外向候选和楔形候选会检查：

\[
N_a\subseteq\operatorname{Cov}(P')
\]

以及

\[
\operatorname{Cov}(P')
\cap
\{v:\sigma(v)\in\{b_N,b_L\},b\ne a\}
=\emptyset.
\]

但代码的“向内方案 A”使用代数面积公式，只显式检查友方节点是否保留，并依赖当前区域无敌方元素这一隐含不变量，没有再次检查敌方点。因此，忠实理论只能把它描述为实现算法；不能把最终 \(P^\star\) 提升为已经证明的全局最短可行围栏。

因为 \((|P|,A(P))\) 是 \(O(N)\times O(N)\) 的非负整数对且严格下降，收紧过程必然终止。它终止在枚举邻域下的局部贪心最优点，不保证全局最优。

### 5.4 判胜面积与显示面积

最终判胜使用

\[
\operatorname{area}_a=A(P^\star).
\]

另一个显示量为

\[
\operatorname{displayArea}_a
=
\left|
\sum_i x_i y_{i+1}-x_{i+1}y_i
\right|.
\]

它是鞋带和的绝对值，没有除以 2；UI 可显示它，但胜负比较不使用它。

## 6. 组合博弈论定位

用组合博弈论术语说，当前规则更接近一个 **partizan scoring-play graph game**：合法行动依赖玩家颜色与基点，终局按计分、跳过与认输决定；它不是 impartial normal-play game。Superko 又使它成为历史依赖博弈，只有在增广状态上才是良基的有限 DAG。

### 6.1 二人版

代码输出胜者而不是数值效用。为得到双人零和模型，可定义

\[
u_B(q_T)=
\begin{cases}
+1,&\operatorname{winner}=B,\\
0,&\operatorname{winner}=\mathrm{DRAW},\\
-1,&\operatorname{winner}=W,
\end{cases}
\qquad
u_W=-u_B.
\]

不能简单把完整效用定义成 area 差，因为一方认输时，面积较小的唯一幸存者仍获胜。

在这个效用下，二人版是有限、确定、完全信息、零和的轮流行动扩展式博弈。第 8 节将证明其增广状态图是 DAG，所以可用逆向归纳定义唯一博弈值：

\[
V(q)=
\begin{cases}
u_B(q),&q\text{ 终局},\\
\max_{a\in\mathcal A(q)}V(T(q,a)),&\tau=B,\\
\min_{a\in\mathcal A(q)}V(T(q,a)),&\tau=W.
\end{cases}
\]

有限 DAG 上的递归良定义，并保证双方存在纯最优策略；这不代表计算这些策略是高效的。

### 6.2 三人版

三人版是有限、确定、完全信息的多玩家顺序博弈，但不是天然的双人零和博弈。引擎只给出

\[
\operatorname{winner}\in\{B,W,P,\mathrm{DRAW}\},
\]

并没有规定联盟、第二名价值或三方数值效用。为把本文的扩展式模型补全，可采用一个明确的分析约定：

\[
u_a(q_T)=
\begin{cases}
+1,&\operatorname{winner}=a,\\
0,&\operatorname{winner}=\mathrm{DRAW},\\
-1,&\operatorname{winner}\in\mathcal C_3\setminus\{a\}.
\end{cases}
\]

这是理论包装层，不是引擎字段，也不是唯一合理偏好。在唯一胜者终局中三方效用和为 \(-1\)，DRAW 时为 0，所以这一个具体包装不是常和。但“是否常和”本身并非引擎规则：同样保持“胜 \(>\) 和 \(>\) 负”次序的

\[
\widetilde u_a=
\begin{cases}
2,&\operatorname{winner}=a,\\
0,&\operatorname{winner}=\mathrm{DRAW},\\
-1,&\operatorname{winner}\ne a
\end{cases}
\]

满足 \(\sum_a\widetilde u_a=0\)。两种基数包装对混合策略和风险的含义并不相同；若改用联盟、名次或领土差偏好，均衡也可能改变。

给定每名玩家完整偏好与平手选择规则后，有限 DAG 仍可逆向归纳得到一个纯子博弈精炼均衡，但均衡通常不唯一，也不能用一个二元 Minimax 标量表示。不随效用包装改变的核心边界是：这里有三名独立控制者。复杂度或学习研究若讨论三人“强制获胜”，必须先说明另外两人是各自优化，还是组成敌对联盟。

### 6.3 为什么不能直接使用 Sprague–Grundy

当前游戏不是标准的无偏正常制组合游戏：

- 双方有不同基点和颜色相关合法集；
- 终局按领土与认输计分，而不是“无子可走者负”；
- 存在和棋、主动 Pass 与 Superko 历史；
- 三人模式超出二人 Sprague–Grundy 框架；
- 长程边、根连通删除和全局泛洪使区域不能自然分解成独立子局。

因此，不能为每个局部区域直接赋一个 nimber 再做异或。桥、割点和小分隔集仍可用于带边界接口状态的动态规划或搜索剪枝，但那是条件分解，不是普通的独立和分解。

### 6.4 增广状态是短博弈，物理盘面不是独立博弈值

对固定的 \(n,m\)，第 8 节的严格秩使完整增广状态图成为有限 DAG。因此它在“无无限行动链”的意义下是一个 **short game form**，可以从终局向前做逆向归纳。这里的基本对象必须是

\[
q=(X,H)
=(\sigma,\mathbf E,\tau,R,c,z,H),
\]

而不是去掉历史的物理规则核 \(X\)。对当前行动者 \(p=\tau(q)\)，定义带值选项集

\[
\mathfrak O_p(q)
=
\left\{
\bigl(a,V_p(T(q,a))\bigr):a\in\mathcal A(q)
\right\}.
\]

第 7.10 节的同核异史见证给出 \(X_A=X_B\) 但 \(\mathcal A(q_A)\ne\mathcal A(q_B)\)，所以 \(X\) 既没有唯一的选项集，也不能被赋予独立于历史的 Conway 形式或 Minimax 值。去掉 \(H\) 的投影虽然含有有向环，但把它直接当作普通 loopy game 也不忠实：某条回边是否存在由整套旧键决定。正确做法是保留 \(H\)，在增广短博弈上求值。

这也给转置表一个严格要求：只按格点、显式边和行动方合并节点是不正确的；即使当前合法动作掩码偶然相同，不同 \(H\) 仍可能在更深层禁止不同后继。

### 6.5 Pass 是节拍资源，不是零游戏

主动 Pass 会改变 \(c\)，可能立即冻结计分，也可能把行动权交给下一名仍有合法落子的玩家，因此它不是“不改变局面的恒等动作”。

若令剩余玩家数 \(r(q)=m-|R|\)，则非终局状态的

\[
b_{\mathrm{pass}}(q)=r(q)-c
\]

可看作当前连续跳过链距离终局的剩余预算：在棋盘与 \(R\) 不变时，每次主动或自动跳过都使它至少减少 1，达到 0 即终局；成功 Place 则把 \(c\) 清零并重新装满这项全局预算。对当前行动者 \(p\)，可定义每个 Place 相对 Pass 的严格节拍收益

\[
U_p(q,a)
=
V_p(T(q,a))-V_p(T(q,\operatorname{Pass})),
\qquad a\in\mathcal A_{\mathrm{Place}}(q),
\]

以及整个决策的结果跨度

\[
D_p(q)
=
\max_{a\in\mathcal A(q)}V_p(T(q,a))
-
\min_{a\in\mathcal A(q)}V_p(T(q,a)).
\]

在三值胜负效用下，\(D_p(q)\in\{0,1,2\}\)。第 7.5 节的可达状态同时满足

\[
D_W(q)=2,
\qquad
\max_{a\in\mathcal A_{\mathrm{Place}}(q)}U_W(q,a)=-2,
\]

即所有实际落子都比 Pass 差到最大幅度。这些量可以严格测量“着点紧迫性”和 Pass-pressure，但不应被称为 Conway 温度：经典温度依赖可组合的数值型子局与冷却运算，而当前规则既不自然分解，效用又主要是离散胜/和/负。若以后采用严格等变的分差效用，可再研究 scoring-play temperature；当前最安全的是把 \(U,D,Z\) 称为操作性节拍指标。

### 6.6 Superko 的历史相互作用距离

令 \(\mathcal P(q)\) 表示合法 Place 集。对具有相同规则核 \(X\) 的两个增广状态，可定义动作掩码距离

\[
d_{\mathrm A}(q,q')
=
\frac{
|\mathcal P(q)\mathbin\triangle\mathcal P(q')|
}{
|\mathcal P(q)\mathbin\cup\mathcal P(q')|
},
\]

并约定并集为空时距离为 0；还可定义结果距离

\[
d_{\mathrm V}(q,q')=|V_p(q)-V_p(q')|.
\]

第 7.10 节的两条真实历史满足 \(|\mathcal P(q_A)|=4\)、\(|\mathcal P(q_B)|=3\)，交集为 3 个动作，故

\[
\boxed{d_{\mathrm A}(q_A,q_B)=\frac14}.
\]

这是一项严格的 Graph History Interaction 指标。八步环的反事实 \(q^-\) 与真实 \(q^+\) 又表明：删除一个旧键会删掉一个值为 \(+1\) 的首着，但另有两个 \(+1\) 首着，所以该对的 \(d_{\mathrm V}=0\)。这说明“博弈形式改变”“最优策略支持集改变”和“标量根值改变”是三件不同的事。当前尚未找到两条标准初局可达的同核历史满足 \(d_{\mathrm V}>0\)。

### 6.7 条件分解而不是普通析取和

若尝试沿一个小分隔集 \(S\) 把棋盘切成区域，足以继续求值的接口至少要记录

\[
I_S(q)=
\bigl(
\sigma|_S,
\mathbf E_{\mathrm{cross}},
\Pi_{\mathrm{root}},
\tau,R,c,
H_{\mathrm{relevant}}
\bigr),
\]

其中 \(\mathbf E_{\mathrm{cross}}\) 是跨分隔集的显式边，\(\Pi_{\mathrm{root}}\) 记录各方边界节点之间以及到本方基点的连通分划，\(H_{\mathrm{relevant}}\) 必须足以回答未来候选键是否已经出现。只有同时证明下列条件，两个区域才可能做条件动态规划：

1. 不会再出现跨区域的共轴连线、攻击或爬行重连；
2. 一侧删除不会经根连通性级联改变另一侧；
3. 终局计分在给定接口后可组合；
4. Superko 的未来重复查询能由接口历史精确回答。

当前规则通常违反四条中的多条。特别是，物理三角格的低度数不能直接给出低 treewidth 算法，因为同轴潜在连线和显式长边建立了 \(\Theta(n^3)\) 个非局部关系。桥、割点和线族超图仍可能产生参数化算法，但必须先证明上述接口充分性；这是一条开放的 FPT/动态规划路线，不是已经得到的分解定理。

这一障碍还有一个简单的严格下界。令潜在可见性图 \(J_n\) 在两个格点共轴时连边；任取一条含 \(n\) 个格点的边界轴线，它在 \(J_n\) 中诱导 \(K_n\)，故

\[
\operatorname{tw}(J_n)\ge n-1.
\]

这只证明“包含全部潜在长程关系”的分解宽度不会为常数；三点限制和可达性是否把实际动态依赖图压到更小宽度，仍是开放问题。

### 6.8 定理：二人最优求值可删除 Resign，但不能删除 Pass

在第 6.1 节的二人胜/和/负效用下，任一非终局状态中当前玩家 \(p\) 若 Resign，立即得到 \(-1\)。Pass 始终合法，而它的后继值必属于 \(\{-1,0,+1\}\)，所以

\[
V_p(T(q,\operatorname{Pass}))
\ge
-1
=
V_p(T(q,\operatorname{Resign})).
\]

因此 Resign 被 Pass 弱支配；从二人精确求解器或最优强化学习动作空间中删除 Resign，不改变任何状态的 Minimax 值。它仍应保留在真实 UI、行为克隆和人类数据模型中。

Pass 则不能这样删除：第 7.5 节已经给出 Pass 为唯一制胜动作、唯一 Place 在最优应对下失败的可达状态。三人局中，认输还可能改变另外两人的收益、联盟与均衡选择；在没有指定完整偏好前，也不能把上述二人支配结论原样迁移过去。

### 6.9 可严格定义的“落子税谱”

若希望得到比三值 \(U,D,Z\) 更细的温度类曲线，可以定义一个派生而非原生的行动税模型。令 \(w(a)\ge0\)，以 Black 的标量效用为准，在同一个增广 DAG 上递归定义

\[
F_\lambda(q)=
\begin{cases}
u_B(q),&q\text{ 终局},\\[1mm]
\displaystyle\max_a\left(F_\lambda(T(q,a))-\lambda w(a)\right),&\tau=B,\\[2mm]
\displaystyle\min_a\left(F_\lambda(T(q,a))+\lambda w(a)\right),&\tau=W.
\end{cases}
\]

有限 DAG 归纳立即给出：\(F_\lambda(q)\) 是有限分段线性函数；若终值与 \(w\) 都为整数，其断点均为有理数。取

\[
w(\operatorname{Place})=1,
\qquad
w(\operatorname{Pass})=w(\operatorname{Resign})=0,
\]

即可研究“给每次落子加税后，最优动作何时切换到 Pass”的阈值。它可以称为 **placement-tax threshold**，并能在小型精确子树上计算；在尚未建立对析取和封闭的 cooling 宇宙前，不能把它改名为已经证明的 Conway temperature。

## 7. 策略窃取、非单调性与“迫移”

### 7.1 经典策略窃取需要什么

Hex 一类经典策略窃取通常依赖至少三个条件：

1. 交换双方后规则与初始几何对称；
2. 不存在后手可利用的和棋；
3. 先手额外放置的己方棋子永远无害，因此可假装它不存在并模拟假设中的后手策略。

第三条是“额外棋子单调性”。当前 LIFELINE 不满足它。

### 7.2 定理：额外己方节点可能减少未来合法落点

对任意 \(n\ge5\)，考虑黑方基点

\[
r_B=(0,0).
\]

候选点

\[
v=(1,0)
\]

在只有基点时是合法的：它不在白方保护区内，与 \(r_B\) 共轴相邻，且三点检查通过。

现在先增加一个黑节点

\[
x=(0,1).
\]

这一步本身合法；随后 \(W\) Pass，重新轮到 \(B\)。此时 \(v\) 同时单位邻接 \(r_B\) 与 \(x\)，所以

\[
|A_B(v)|=2,
\]

非攻击落子 \(v\) 被三点限制禁止。

因此，加入一个己方节点会严格缩小某些未来合法落点集合。证毕。

当前实现还有一个完全可达的反方向反例，说明“增加己方结构”也可能给对手创造新行动。在 \(n=5\) 双人局中依次执行

\[
B:(0,2),\qquad
W:(2,0),\qquad
B:(1,2).
\]

此时轮到 \(W\)：

- 若 \(W\) Pass，则 \(B\) 在 \((2,1)\) 的普通落子会触发三点限制，因而非法；
- 若 \(W\) 落在 \((2,2)\)，新白线经过 \((2,1)\)；
- 随后 \(B\) 落在 \((2,1)\) 变成攻击落子，获得三点限制豁免，因而合法。

所以一方新增的节点与线可以扩大对手的合法攻击集合。上述两条序列已经用当前 GameEngine.js 直接验证；它们共同否定了“多一个己方结构只可能有利、且不会给对手新增行动”的动作单调性。

### 7.3 可以推出什么，不能推出什么

上述两个反例共同证明：

> 依赖“任意额外己方棋子都无害”的经典额外棋子型策略窃取证明，不能直接应用于当前规则。

它没有证明：

- 后手存在必胜策略；
- 当前游戏存在某个实际可达的经典 Zugzwang；
- 所有可能形式的策略窃取都失效；
- 额外节点一定降低整个局面的 Minimax 值。

合法行动集合非单调，只是否定了旧证明的一个必要前提，不等于完成相反胜负结论的证明。

### 7.4 为什么“被迫落子”不是当前规则事实

Pass 在任何非终局状态都合法，即使玩家还有很多合法落点。真正自动发生的只是“没有合法落点时自动跳过”，从来不是“被迫选择某个落点”。

所以当前规则下更准确的研究对象是：

- 所有落子都劣于 Pass 的 pass-pressure 局面；
- 禁止主动 Pass 的变体中的 placement-zugzwang；
- 额外节点导致的合法性或价值非单调。

固定当前玩家 \(a\) 的三值 Minimax 效用 \(V_a\in\{-1,0,1\}\)。在至少有一个合法落点的状态中定义

\[
Z_a(q)
=
V_a(T(q,\operatorname{Pass}))
-
\max_{v\in\mathcal L_a(q)}
V_a(T(q,\operatorname{Place}(v))).
\]

\(Z_a(q)>0\) 表示 Pass 严格优于每一个实际落子，但不表示玩家被规则强迫落子。Pass 会增加连续跳过计数并可能立即终局，所以它也不是无代价的“空着”。

### 7.5 定理：当前引擎存在最大强度的严格 Pass-pressure

取 \(n=5\)，从标准初始局面依次执行

\[
\begin{aligned}
&B(1,0),\ W(2,0),\ B(1,2),\ W(2,1),\\
&B(0,2),\ W(1,1),\ B(0,4),\ W(1,3),\\
&B\operatorname{Pass}.
\end{aligned}
\]

得到可达状态 \(q\)：轮到 \(W\)，\(c=1\)，面积为 \((7,8)\)，历史集合含 9 个键。逐点检查全部 15 个格点，\(W\) 唯一合法落点是 \((0,3)\)。完整关键分支为：

1. \(W\operatorname{Pass}\)：\(c=2\)，立即终局，\(W\) 以 \(8:7\) 获胜；
2. \(W\operatorname{Resign}\)：\(B\) 获胜；
3. \(W(0,3)\)：面积先变为 \((5,9)\)。此后 \(B\) 若 Pass 或 Resign，\(W\) 获胜；\(B\) 唯一合法落点是 \((2,2)\)，它也是 \(B\) 唯一的制胜动作。\(B(2,2)\) 后面积变为 \((6,5)\)，\(W\) 无合法落点而自动跳过；\(B\) 再 Pass，立即以 \(6:5\) 获胜。

因此

\[
V_W(T(q,\operatorname{Pass}))=+1,
\qquad
\max_v V_W(T(q,\operatorname{Place}(v)))=-1,
\]

从而

\[
\boxed{Z_W(q)=2},
\]

达到三值效用下的最大可能值。当前规则中 \(W\) 会选择 Pass，所以这不是法律意义上的被迫落子。若只在给定决策状态 \(q\) 中删除主动 Pass，\(W\) 的唯一落子在最优应对下失败，因而 \(q\) 作为抽象位置是严格 Zugzwang；但上述到达 \(q\) 的历史本身使用了 \(B\) 的主动 Pass，所以它尚未证明 no-Pass 变体从标准初局可达某个 Zugzwang。已证明的无条件结论是：当前实现存在严格的 Place-vs-Pass 动作价值反转与最大 Pass-pressure；这不等同于在保持行动方和其他条件可比时，额外放入一个己方节点会降低整个状态值。

### 7.6 非计分规则核的反射等变性

定义交换两个二人基点的反射

\[
\theta(x,y)=(n-1-x-y,y),
\]

并同时交换黑白节点、线点、显式边、行动方、认输标签和历史键；\(c\) 与终局标志保持。记完整变换为 \(\Theta\)。

排除领土缓存与最终 winner 后，当前规则核满足：若 \(a\) 在 \(q\) 合法，则 \(\Theta a\) 在 \(\Theta q\) 合法，并且

\[
\Theta T(q,a)=T(\Theta q,\Theta a).
\]

理由是 \(\theta\) 保持六邻接、三族共轴关系和离散线段；它交换两个基点及保护区，保持三点限制；阻挡、显式边完整性、根连通 BFS、删除、旧边恢复和六射线首节点重连均只依赖这些被保持的关系。对 \(H\) 逐键变换后，Superko 的集合成员关系也被保持。Pass、Resign 与 Normalize 只依赖玩家轮换、\(R\)、\(c\) 和“是否存在合法落点”，所以同步发生。

领土计算不在这一定理内。固定的轮廓起点、方向和枚举次序不是几何关系，事实上会破坏下面的终局对称。

### 7.7 弱 Pass 策略窃取定理

考虑标准双基点初始局面 \(q_0\)，且 \(B\) 起手；这里 \(T\) 总是包含动作后的完整 Normalize，\(\Theta\) 是二人规则核上的对合。策略允许依赖完整公开历史，并可在内部维护一条反事实历史；第 8 节的有限 DAG 保证任意策略组合都会终止。要排除“后手 \(W\) 严格必胜”，不需要精确面积等变，只需要：

1. 第 7.6 节的转移等变性；
2. 对每个相关终局 \(t\)，有单向性质
   \[
   u_W(t)=+1\Longrightarrow u_B(\Theta t)\ge0;
   \]
3. 初始局面双方连续 Pass 为和棋。

**定理。** 在这三个条件下，后手 \(W\) 不存在严格必胜策略。

**证明。** 反设 \(W\) 有必胜策略 \(\pi\)。\(B\) 首手 Pass。若 \(W\) Pass，则立即和棋；若 \(W\) Resign，则失败。因此 \(\pi\) 必须回答 Place\(_W(v)\)。定义实际状态与反事实状态

\[
q_A(v)=T\!\left(T(q_0,\operatorname{Pass}_B),\operatorname{Place}_W(v)\right),
\]

\[
q_C(v)=T\!\left(q_0,\operatorname{Place}_B(\theta v)\right).
\]

首个 Place 把两边的 \(c\) 都重置为 0。实际的 \(B\) 内部维护反事实历史 \(q_C\)：每当实际轮到 \(B\) 决策时，查询 \(\pi\) 在对应反事实状态中为 \(W\) 选择的动作，再执行其 \(\Theta\)-像；实际 \(W\) 的每个动作则定义反事实对局中 \(B\) 的动作。自动跳过不是策略动作，并由两边的 Normalize 同步发生。于是反事实对局中的 \(W\) 始终执行 \(\pi\)，故每个反事实终局都是 \(W\) 胜；由条件 2，对应实际终局中 \(B\) 至少不败。这与 \(\pi\) 能战胜每个实际 \(B\) 策略矛盾。证毕。

这里还有一个 Superko 细节。应比较“实际序列 \(B\) Pass、\(W(v)\) 完成后”的历史 \(H_A\)，与“反事实序列 \(B(\theta v)\) 完成后”的历史经 \(\Theta\) 变换所得集合 \(\Theta H_C\)。二者的对称差恰为两个裸初始键

\[
H_A\triangle\Theta H_C=\{h_B^0,h_W^0\}.
\]

每次成功 Place 在 Normalize 之前计算候选键，此时必含刚落下的非基点己方节点；节点不能被直接覆盖，而本次攻击只删除对方结构。因此后续候选键不可能等于只有两个基点的裸初始键。也就是说，把 \(h_W^0\) 换成 \(h_B^0\) 只得到一个行为等价状态：两边以后所有 Place 的 Superko 合法性相同，而终局效用又不读取 \(H\)。故上述反事实模拟严格成立。

### 7.8 定理：当前 winner 不满足完整镜像等变

当前引擎中有一个只需 10 次落子、无中途 Pass 的 \(n=7\) 可达反例：

\[
\begin{aligned}
&B(1,0),\ W(5,1),\ B(4,0),\ W(2,1),\ B(0,5),\\
&W(2,3),\ B(1,2),\ W(1,4),\ B(0,3),\ W(0,4).
\end{aligned}
\]

落子后面积为

\[
(A_B,A_W)=(10,10).
\]

再由 \(B,W\) 连续 Pass，终局为 DRAW。把全部状态按 \(\Theta\) 变换，以 \(W\) 起手逐手执行对应镜像序列，得到

\[
(A_B,A_W)=(11,10),
\]

再由 \(W,B\) 连续 Pass，终局却是 BLACK 胜。该镜像物理状态也可从默认 \(B\) 起手局经“\(B\) 先 Pass，再走镜像序列”到达。因此这不是非法数组拼装造成的假反例。

和棋在换色反射后本应仍是和棋，所以这个例子同时反驳了精确 area 等变和完整胜负效用等变。

根因已经定位到贪心收紧的**表示依赖**。反例中对应双方的外轮廓确实只是同一闭合轮廓的循环移位与反向，初始目标均为 \((|P|,A)=(15,9)\)。当前算法却把闭合轮廓当成有起点和方向的数组，按 \(i,j\)、BFS 前驱和路径顺序枚举；目标 \((|P|,A)\) 相同的候选保留先遇到者。两边第一轮都到 \((14,10)\)，但进入不同多边形：一边停止，另一边继续到 \((13,11)\)。对同一个 15 点轮廓穷举 15 个循环起点和正反两个方向，19 种表示到 \((13,11)\)，11 种到 \((14,10)\)。泛洪本身保持反射；破坏等变的是“线性表示—先遇到者—不同局部盆地”的组合。

这个 DRAW\(\to\)BLACK 反例尚未反驳第 7.7 节更弱的单向性质。对该反例附近 37 个合法替换状态及另外 1000 条确定性随机合法轨迹，没有发现“原局 \(W\) 严格胜、镜像后 \(B\) 仍严格负”的例子；这只是测试覆盖，不是证明。因此当前默认初始局面是否先手至少不败仍是开放问题。

### 7.9 三种可证明恢复公平的计分定义

令 \(\operatorname{Raw}_c(q)\) 表示当前实现给玩家 \(c\) 的原始面积。

**方案 A：玩家基点规范坐标。** 令 \(T_B=\mathrm{id}\)，\(T_W=\Theta\)，并在 \(T_cq\) 中把被评分玩家统一命名为 \(B\)：

\[
A_c^{\mathrm{can}}(q)=\operatorname{Raw}_B(T_cq).
\]

于是直接有

\[
A_W^{\mathrm{can}}(q)=A_B^{\mathrm{can}}(\Theta q).
\]

每方仍只运行一次 raw 算法，总次数与现在相同；含义是“每名玩家都从自己的基点朝同一标准方向运行同一算法”。新反例会变成原局 \((10,11)\)、镜像局 \((11,10)\)，胜者严格交换。

**方案 B：双方向取紧。** 定义

\[
\widehat A_c(q)
=
\min\bigl\{
\operatorname{Raw}_c(q),
\operatorname{Raw}_{\bar c}(\Theta q)
\bigr\}.
\]

交换两项立即证明

\[
\widehat A_{\bar c}(\Theta q)=\widehat A_c(q).
\]

它从不增加当前 raw 分数，最符合“皮筋尽量收紧”的语义；新反例两边都恢复为 \((10,10)\)。代价是通常要同时计算 \(q\) 与 \(\Theta q\) 的双方领土，即约两倍总开销。

**方案 C：轨道求和。** 也可定义

\[
A_c^{\Sigma}(q)
=
\operatorname{Raw}_c(q)
+
\operatorname{Raw}_{\bar c}(\Theta q).
\]

它同样严格等变，比较整数和即可，不必除以 2。三种方案都继续采用“唯一面积最大者获胜、并列 DRAW”的规则，并保持 Resign 终局不变；因此面积向量等变会推出完整终局效用等变。采用 A、B 或 C 中任一方案后，第 7.7 节条件 2 自动成立，因而双人标准初局的后手不可能严格必胜。

若要保留一次 raw 算法的内部语义而直接修代码，一个候选方向是在玩家局部坐标中把每个闭合轮廓规范化为全部循环移位与反向中的唯一 key；每轮枚举完所有候选后，按

\[
(\operatorname{perimeter},\operatorname{area},\operatorname{canonicalKey})
\]

全局选最小者，并在下一轮前再次规范化。这里 canonicalKey 只能在相同 \((\operatorname{perimeter},\operatorname{area})\) 的候选之间打破平局；被选候选仍须在前两项上严格优于当前轮廓，不能引入同目标 plateau 转移。这个方案消除了已知的“先遇到者”不确定性，但要把整个 raw 算法的等变性提升为定理，还须对所有可达友方集合证明：`_getOuterContour` 在群作用下给出的 outer-face walk 总是仅相差循环移位或反向，且最短路径候选集合也在变换下闭合。完成这些证明前，A、B、C 才是已有形式保证的修复；局部 canonicalKey 仍是工程候选。

三人局若要求完整三角形对称群 \(D_3\) 而不只是三角旋转 \(C_3\)，必须让 \(D_3\) 同时作用于三角格坐标和基点标签 \(B,W,P\)。为每个玩家 \(c\) 选取一个变换 \(T_c\)，把 \(c\) 的基点及标签送到标准标签 \(B\)；此后还剩一个大小为 2 的带标签稳定子群 \(\operatorname{Stab}(B)\)。可定义

\[
A_c^{D_3}(q)
=
\min_{h\in\operatorname{Stab}(B)}
\operatorname{Raw}_B(hT_cq),
\]

于是对任意 \(g\in D_3\) 都有

\[
A_{gc}^{D_3}(gq)=A_c^{D_3}(q).
\]

这是因为 \(T_{gc}gT_c^{-1}\in\operatorname{Stab}(B)\)，与这个稳定子群元素相乘只会置换取最小值时的两个群元素；同理，更换截面 \(T_c\) 也不改变结果。该定义每名玩家需要 2 次 raw 计算，三人全局共 6 次，从而消除坐标截面的任意选择并得到完整 \(D_3\) 等变。

### 7.10 Superko 严格破坏历史盲复制，但尚未造成价值反转

把不含历史集合的规则核写成

\[
X=(\sigma,\mathbf E,\tau,R,c,z),
\]

完整状态则为 \(q=(X,H)\)。对一个非 Superko 条件已经全部通过的 Place 动作 \(a\)，记动作结算后的候选键为 \(K(X,a)\)。令 \(\widehat\Theta\) 表示第 7.6 节变换在序列化键上的作用。

考虑一对耦合状态

\[
q_A=(X_A,H_A),\qquad q_B=(X_B,H_B),\qquad X_A=\Theta X_B,
\]

以及一对镜像动作 \(a_A=\Theta a_B\)。规则核等变性给出

\[
K(X_A,a_A)=\widehat\Theta K(X_B,a_B).
\]

定义历史差集

\[
D=H_A\mathbin\triangle\widehat\Theta(H_B).
\]

在两侧的非 Superko 合法性相同这一前提下，两动作的 Superko 合法性不同，当且仅当

\[
K(X_A,a_A)\in D.
\]

这是因为 Superko 最后只查询候选键是否属于各自历史集合。特别地，若

\[
H_A=\widehat\Theta(H_B),
\]

则 \(D=\varnothing\)，Superko 不可能自行破坏镜像模拟。相反，只同步当前盘面与显式边而不维护历史耦合，原则上没有合法性保证。

当前引擎中已经存在一个不依赖人工拼装历史的严格见证。取 \(n=6\)，从标准双人初局分别执行：

\[
\begin{aligned}
\eta_A:\;&B(1,0),W(4,1),B(1,2),W(1,4),\\
&B(0,4),W(2,3),B(3,2);\\[2mm]
\eta_B:\;&B(1,0),W(4,1),B(0,4),W(1,1),B(3,1),\\
&W(1,4),B(1,2),W(1,3),B(3,2).
\end{aligned}
\]

两条历史都完全合法，并到达同一个规则核 \(X\)：格点标记逐点相同、双方显式边集相同、轮到 \(W\)、\(R=\varnothing\)、\(c=0\)、\(z=0\)，面积均为 \((11,0)\)。但历史大小分别为

\[
|H_A|=8,\qquad |H_B|=10.
\]

此时同一攻击 \(W(1,1)\)：

- 在 \((X,H_A)\) 中合法；
- 在 \((X,H_B)\) 中满足全部几何、三点、连通、攻击与恢复条件，却产生 \(\eta_B\) 第 4 手后已经记录的键，因此唯一失败原因为 `SUPERKO_VIOLATION`。

两边完整合法 Place 集分别为

\[
\mathcal L(X,H_A)=\{(2,0),(3,0),(1,1),(2,1)\},
\]

\[
\mathcal L(X,H_B)=\{(2,0),(3,0),(2,1)\},
\]

所以差集恰为 \(\{(1,1)\}\)。

所以已经严格证明：**两个都从标准初局可达、且当前规则核完全相同的状态，可以仅因历史不同而拥有不同的合法动作集。** 因而 \(X\) 不是足以决定合法动作的 Markov 状态；若无额外历史安全证明，只写 \(\pi(X)\) 不能表示一般的完整策略，也不能保证把一个给定应手复制到另一个同核状态后仍然合法。

另一个可达见证还能精确测量这种分叉的博弈强度。第 8.3 节的 13 手状态记为

\[
q^+=(X_{13},H_{13}),
\]

并令

\[
q^-=(X_{13},H_{13}\setminus\{h_6\}),
\]

其中 \(h_6\) 是第 6 手后写入的键。唯一删除 \(h_6\) 后，\(W(0,3)\) 从 Superko 禁手恢复为合法制胜着。使用真实 Place、Pass、自动跳过、完整 \(H\) 与真实终局面积的无剪枝精确 Minimax，得到：

| White 的根动作 | \(q^-\) 中的值 | \(q^+\) 中的值 |
|---|---:|---:|
| \(W(0,3)\) | \(+1\) | Superko 非法 |
| \(W(2,0)\) | \(+1\) | \(+1\) |
| \(W(2,1)\) | \(+1\) | \(+1\) |
| \(W(1,2)\) | \(-1\) | \(-1\) |
| Pass | \(-1\) | \(-1\) |

两边根值都是

\[
V_W(q^-)=V_W(q^+)=+1.
\]

搜索分别访问 83,957 与 50,028 个递归节点，转置状态数分别为 55,865 与 34,039；Resign 在尚有两名玩家时立即给行动方 \(-1\)，故可安全省略。若定义制胜动作集

\[
\mathcal W(q)=\{a:V_W(T(q,a))=+1\},
\]

则

\[
\mathcal W(q^-)=\{(0,3),(2,0),(2,1)\},
\qquad
\mathcal W(q^+)=\{(2,0),(2,1)\}.
\]

因此 Superko 确实删掉了一个制胜应手，并且由于 Pass 和 \((1,2)\) 都输，White 若要维持强制胜必须改走两个替代 Place 之一。这可以称为**战略上的强制绕行**，但不是规则强迫的唯一落子，更不是 Zugzwang：Pass 在语法上仍合法，且还有两个制胜替代。

结论强度必须分三层：

1. **合法性分叉：** 同一个被复制动作只在一侧合法；本节的两条真实历史已经证明。
2. **策略分叉：** 某个指定制胜策略确实要求这个动作；13 手见证对选择 \((0,3)\) 的策略成立，而且制胜动作集严格缩小。
3. **价值反转：** \(V(X,H^-)\ne V(X,H^+)\)，或镜像策略的唯一保值应手被禁且没有替代；当前仍未找到。

第 7.7 节标准初局“Black 首手 Pass”的弱策略窃取定理不受这个反例推翻。那一特殊耦合的历史差只有两个裸初始键，而后续成功 Place 的候选键不可能等于裸双基点局面，所以差集永远不会被命中。故目前最强的正确表述是：

> Superko 严格否定“历史盲的逐动作复制总是合法”这一普遍原则，并能迫使一个制胜策略改道；它没有自动否定携带完整历史耦合的策略窃取，也尚未造成已证明的 Minimax 胜负值反转。

可执行复核见 [verify-superko-history-divergence.mjs](./verify-superko-history-divergence.mjs)：默认快速验证两条真实历史和八步闭环；加入 `--solve` 后运行无剪枝精确 Minimax，并输出上表的两组动作值与节点数。

## 8. Superko 增广图是 DAG

### 8.1 仅靠 \(|H|\) 的旧证明为什么错

成功落子产生新序列化位置并加入 \(H\)，所以“只包含成功落子的子图”以 \(|H|\) 为严格秩，确实是 DAG。

但主动 Pass、自动跳过与 Resign 都不增加 \(H\)。因此，“完整游戏每一步都令 \(|H|\) 增加”是错误命题。

### 8.2 定理：完整增广规则图是 DAG

把已经 Normalize 的决策状态与终局状态作为图顶点，并把一次玩家动作及随后确定性的 Normalize 视为一条规则转移。定义

\[
\rho(q)
=(m+1)^2|H|+(m+1)|R|+c.
\]

对非终局合法状态，有 \(0\le c\le m-1\)。

**成功落子。** Superko 要求 \(K'\notin H\)，随后

\[
|H'|=|H|+1.
\]

即使 \(c\) 从最多 \(m-1\) 重置为 0，

\[
\Delta\rho
\ge
(m+1)^2-(m-1)>0.
\]

其后的自动跳过只会进一步增大 \(c\)。

**认输。** \(H\) 不变，\(|R|\) 增加 1，\(c\) 重置。于是

\[
\Delta\rho
\ge
(m+1)-(m-1)=2>0.
\]

**主动或自动跳过。** \(H,R\) 不变，而 \(c\) 至少增加 1；达到剩余玩家数时进入终局。因此

\[
\Delta\rho>0.
\]

每条合法非空转移都严格增加整数秩 \(\rho\)，所以完整增广状态转移图不存在有向环。证毕。

正确结论是：

> 包含显式边、行动方、认输集合、连续跳过、终局标志和历史集合的完整增广游戏图是 DAG。

不应写成“去掉历史的位置图是 DAG”，也不应写成“Superko 序列化键本身足以表示完整状态”。序列化键不含 \(c\) 与 \(z\)，二次 Pass 甚至可能在不改变该键的情况下终局。

### 8.3 定理：位置投影中存在可达八步环，Superko 截断闭环边

令规则核 \(X_t\) 表示第 \(t\) 手后的格点、显式边、行动方、认输集合、连续跳过数与终局标志，但不包含 \(H\)。在 \(n=6\) 标准双人初局中执行

\[
\begin{aligned}
&B(0,5),W(3,0),B(1,0),W(4,1),B(0,4),W(0,3),\\
&B(1,2),W(0,5),B(0,4),W(1,1),B(3,1),W(1,4),B(3,2).
\end{aligned}
\]

全部 13 手合法。此时轮到 \(W\)，面积为 \((13,4)\)。攻击 \(W(0,3)\) 通过除 Superko 外的全部规则检查；暂时结算后的候选键严格等于第 6 手后已经写入的键 \(h_6\)，所以真实引擎返回 `SUPERKO_VIOLATION`。

若只为反事实分析删去 \(h_6\)，该攻击立即合法，而且动作后的格点、显式边、行动方、\(R,c,z\) 与序列化键全部精确等于第 6 手后的规则核：

\[
X_{14}=X_6.
\]

因此，忽略历史成员资格的规则核投影中存在真实有向环

\[
X_6\to X_7\to\cdots\to X_{13}\to X_6,
\]

共八条边。当前 Superko 恰好删除最后一条闭环边。这个见证同时说明两点：

- 第 8.2 节的 DAG 性质真正来自增广历史，不是物理盘面天然单调；
- 旧的非初始键确实会被未来候选动作命中，\(H\) 不是只用于理论上界的惰性字段。

候选攻击若被允许，面积会立即从 \((13,4)\) 变为 \((0,8)\)，双 Pass 冻结计分也从 Black 胜变为 White 胜；但第 7.10 节的完整 Minimax 已证明 White 仍有两个绕行制胜着，所以这一局部翻分不等于根价值反转。

## 9. 状态、深度与搜索空间上界

### 9.1 物理点与潜在边

格点数为

\[
N(n)
=
\sum_{\ell=1}^{n}\ell
=
\frac{n(n+1)}2.
\]

三族轴线各有长度 \(1,\ldots,n\) 的线各一条，所以潜在共轴端点对为

\[
Q(n)
=
3\sum_{\ell=1}^{n}\binom{\ell}{2}
=
3\binom{n+1}{3}
=
\frac{n^3-n}{2}.
\]

不同格点对至多共享三族轴线中的一族，因此没有重复计数。

### 9.2 配置与哈希位置上界

每格有 \(2m+1\) 种状态。对每个潜在端点对，合法显式边至多为“无边”或“属于某一名玩家”，共 \(m+1\) 种。于是物理层加边层的安全上界为

\[
C_m(n)
\le
(2m+1)^{N(n)}(m+1)^{Q(n)}.
\]

Superko 键还编码下一位玩家和认输集合，因此

\[
\boxed{
P_m(n)
\le
m\,2^m(2m+1)^{N(n)}(m+1)^{Q(n)}
}.
\]

这只是上界。绝大多数组合不满足端点颜色、边投影、根连通、保护区、三点限制或可达历史等不变量。

若完全按 \(m\) 个独立 Set 的原始数据结构计数，还可写更松的

\[
P_m^{\mathrm{raw}}(n)
\le
m\,2^m(2m+1)^N2^{mQ}.
\]

两种口径对固定 \(m\) 都是 \(2^{O(n^3)}\)。

具体地，

\[
P_2(n)\le8\cdot5^N3^Q,
\qquad
P_3(n)\le24\cdot7^N4^Q.
\]

| \(n\) | \(N\) | \(Q\) | 双人物理+边 \(C_2\) | 双人完整键 \(P_2\) | 三人完整键 \(P_3\) |
|---:|---:|---:|---:|---:|---:|
| 9 | 45 | 360 | \(1.649308\times10^{203}\) | \(1.319447\times10^{204}\) | \(1.416511\times10^{256}\) |
| 15 | 120 | 1680 | \(2.754917\times10^{885}\) | \(2.203933\times10^{886}\) | \(1.789623\times10^{1114}\) |

若只统计“尚无人认输”的双人键，可去掉认输集合因子：

\[
2\cdot5^{45}3^{360}
=3.298617\times10^{203},
\]

\[
2\cdot5^{120}3^{1680}
=5.509833\times10^{885}.
\]

旧文档中的相应小数也应以这两个值为准。

### 9.3 增广历史状态空间

\(H\) 是最多 \(P_m\) 个键的子集。再计入当前位置、连续跳过和终局标志，

\[
\boxed{
|\Omega_{\mathrm{aug}}|
\le
2(m+1)P_m\,2^{P_m}
}
=
2^{2^{O(n^3)}}.
\]

这个双指数是历史自动机的状态空间上界，不等于一盘棋的长度。

### 9.4 最长对局

初始历史已有一个键。每次成功落子加入一个此前未出现的键，所以成功落子数 \(L\) 满足

\[
L\le P_m-1.
\]

为避免与第 8 节的“玩家动作加 Normalize 为一条图边”混淆，本节的 \(D_m\) 按 primitive events 计数，即把自动跳过也单独计入；规范化决策图的边深度只会更小。终局前至多有 \(m-1\) 次认输。令

\[
X=L+R_{\mathrm{act}}\le P_m+m-2
\]

为会重置连续跳过数的行动数。每个非终局行动段之前至多有 \(m-1\) 次 Pass，最终终局段至多有 \(m\) 次 Pass，因此总深度 \(D_m\) 满足

\[
D_m
\le
X+(m-1)X+m
=mX+m
\le
\boxed{m(P_m+m-1)}.
\]

所以

\[
D_m(n)\le2^{O(n^3)}.
\]

### 9.5 分支因子与博弈树

当前玩家至多选择 \(N\) 个落点，再加 Pass 与 Resign：

\[
\boxed{B_m(n)\le N(n)+2=O(n^2)}.
\]

自动跳过没有选择分支。朴素、不合并转置的博弈树满足

\[
|\mathcal T|
\le
\sum_{d=0}^{D_m}B_m^d
<
(N+2)^{D_m+1}
\le
2^{2^{O(n^3)}}.
\]

代入完整键上界，可得到非常松但明确的数值：

| 棋盘与玩家数 | 朴素博弈树上界 |
|---|---:|
| \(n=9,m=2\) | \(<10^{\,4.412488\times10^{204}}\) |
| \(n=9,m=3\) | \(<10^{\,7.105635\times10^{256}}\) |
| \(n=15,m=2\) | \(<10^{\,9.196396\times10^{886}}\) |
| \(n=15,m=3\) | \(<10^{\,1.120139\times10^{1115}}\) |

这些数是“表示上界套上深度与分支上界”的结果，不是可达局面数、平均搜索量或紧确 Shannon 数。

### 9.6 为什么三态压缩不适用

\[
2\cdot3^{N(n)}
\]

只统计空、黑节点、白节点与行动方。它同时假定：

- 线点由节点唯一决定；
- 显式边由节点唯一决定；
- 不需要认输、连续跳过或历史；
- 每次都按一个唯一闭包规则重建全部连接。

当前实现违反前两条，完整规则还违反后两条。因此该公式只能属于另行定义并证明闭包唯一的理想化变体，不能继续标为“当前游戏的 no-Superko 等价压缩”。

## 10. NP、NP-hard 与更高复杂度

### 10.1 先定义问题

复杂度类描述决策语言。“输入一个合法状态”还会混淆局部一致与真实可达，因此至少应区分：

1. \(\textsc{START-LIFELINE-WIN}\)：输入只有一元编码的 \(n\) 和常数个起手参数，从标准初始局面开始；
2. \(\textsc{POSITION-LIFELINE-WIN}_{\mathrm{syn}}\)：输入
   \[
   (n,\sigma,\mathbf E,\tau,R,c,H)
   \]
   及指定玩家，只要求字段满足局部类型与一致性约束，不承诺可达；
3. \(\textsc{POSITION-LIFELINE-WIN}_{\mathrm{reach}}\)：承诺输入状态从标准起点真实可达，且 \(H\) 正是某条合法历史产生的集合；
4. \(\textsc{HISTORY-LIFELINE-WIN}\)：直接输入一条合法行动记录，由引擎重放生成状态和 \(H\)。

四者都问指定玩家是否存在策略，对对手的所有合法策略严格获胜。三人版还必须说明另外两人的效用与联盟模型。

只有 \(n\) 的 START 版本每个长度只有常数个实例，没有自然位置编码来放置一般源问题的变量和约束；现有 gadget 路线应瞄准 POSITION 或 HISTORY 版本。预置任意节点、边或历史禁手的归约最多证明 syntactic-position 版本；要证明 reachable-position 版本，必须给出并证明一条多项式长度的合法构造历史，若目标是 HISTORY 版本则还须把该历史作为输出编码的一部分。

实际程序把 \(n\) 限制在 15，只产生有限实例族。以下渐近结论统一假设解除上限，采用明确的多项式展开编码：例如一元 \(n\) 加稀疏边表，或显式稠密棋盘与边位向量；\(H\) 显式列出或由显式历史生成。不讨论用电路隐式表示巨大 \(H\) 的另一种 succinct 问题。

### 10.2 当前可证明的 membership 上界

取一个不含历史集合的规范稠密工作表示，其长度为

\[
s=\Theta(Q(n))=\Theta(n^3).
\]

于是

\[
P_m(n)\le2^{O(s)},
\qquad
D_m(n)\le2^{O(s)}.
\]

令完整输入长度为 \(L\)。对上述编码总有 \(s=O(\operatorname{poly}(L))\)；只有在显式填满全部潜在边位的稠密编码下才可进一步写成 \(L\ge s\)。即使输入时 \(H\) 很小，未来路径仍可能积累 \(2^{O(s)}\) 个键。深度优先的 Minimax 搜索用可回滚的全局历史集合保存当前分支，并记录指数深度的动作栈和多项式大小的局面工作区，因此对上述显式输入版本都有安全上界

\[
\boxed{\textsc{LIFELINE-WIN}\in\mathrm{EXPSPACE}}.
\]

完整展开搜索树及每步计算给出

\[
\boxed{\textsc{LIFELINE-WIN}\in 2\text{-}\mathrm{EXPTIME}}.
\]

这里的指数与双指数都是关于 \(L\) 的多项式指数；EXPSPACE 是更有信息量的空间 membership 结论。它们都不是完备性结论，也不把 promise 输入的可达性验证自动算作已经解决。

### 10.3 单步与领土计算

给定显式 \(H\)，判断一个候选落点是否合法不需要领土计算：连线、断边、BFS、重连和 Superko 查找都可在输入表示的多项式时间内完成。

但当前领土实现会一次性物化一对顶点之间的所有最短路径。六邻接图中的最短路径条数可以指数增长。令 \(N=N(n)\)，一个安全粗界为

\[
T_{\mathrm{territory}}(n)
\le
O(N^5 6^N)
=2^{O(n^2)}.
\]

当前实现的峰值内存也可能是 \(2^{O(n^2)}\)。若以 DFS 流式枚举路径，可在不改变枚举顺序与贪心选择的前提下降低到多项式工作空间，但时间仍可能指数级。

领土不影响落子合法性，却影响公开 playMove 的缓存更新时间和终局胜负。复杂度论述必须把“规则合法性转移”和“按当前算法计算计分缓存”分开。

### 10.4 现在不能声称什么

| 命题 | 当前状态 |
|---|---|
| 候选落子合法性 | 在 P |
| 显式位置/历史版双人强制获胜 | 在 EXPSPACE，也在 \(2\)-EXPTIME |
| 属于 NP | 未证明，也不是自然默认 |
| NP-hard | 未证明 |
| PSPACE-hard | 未证明 |
| EXPTIME-hard / EXPSPACE-hard | 未证明 |
| PSPACE-complete 等完备性 | 未证明 |
| 第 10.7 节的抽象守卫图变体 | PSPACE-complete，但不是当前规则 |

“给出一条获胜走法即可验证”不能证明强制获胜属于 NP。强制获胜要求对手所有应手都被覆盖，证书通常是一棵策略树，而不是一条合作式对局轨迹，并且当前深度本身可以指数大。

### 10.5 Pass 消去引理

设 \(q\) 是尚有两名玩家的非终局状态，行动方为 \(a\)。冻结棋盘、边、历史和认输集合，只让双方继续 Pass；若所得终局严格判 \(\bar a\) 获胜，则：

> \(\operatorname{Pass}\) 不可能是 \(a\) 的强制获胜策略的第一步。

证明很直接。若 \(a\) 的这次 Pass 已达到连续跳过阈值，则立即进入同一个冻结计分终局；否则轮到 \(\bar a\)：若其有合法落点，可以主动 Pass，若没有合法落点，引擎会自动 Pass。所有情况都在未改变计分盘面的情况下完成连续跳过，故 \(\bar a\) 获胜。Resign 更是立即失败。证毕。

因此 hardness 归约不必从语法上删除 Pass。只要每个模拟决策态都维持节拍不变量

\[
\operatorname{Winner}(\operatorname{Freeze}(q))
=
\text{非行动方},
\]

Pass 就是可被对手立即惩罚的非获胜动作。一个自然实现目标是让每个模拟落子把严格领先翻给刚落子者，从而使下一行动方暂时落后。

### 10.6 当前引擎中的两步节拍与 Col 冲突见证

以下不是完整归约，但它证明节拍计分与三点限制可以在真实可达状态中同时工作。取 \(n=7\)，依次执行

\[
B(1,0),\quad W(2,4),\quad B(1,3),\quad W(4,0).
\]

此时轮到 \(B\)，面积为 \((5,8)\)。令

\[
u=(0,4),\qquad v=(1,4).
\]

直接逐点复核得到：

1. \(u,v\) 对双方都合法；\(B\) 若 Pass，\(W\) 可 Pass 并以 \(8:5\) 获胜；
2. \(B(u)\) 后面积为 \((9,8)\)；此时 \(v\) 同时单位邻接新黑节点 \(u=(0,4)\) 与既有黑节点 \((1,3)\)，所以 \(v\) 对 \(B\) 因三点限制非法，对 \(W\) 仍合法；
3. 此时 \(W\) 若 Pass，\(B\) 可 Pass 并以 \(9:8\) 获胜；
4. \(W(v)\) 后面积为 \((9,11)\)，领先再次翻给刚落子的玩家。

所以这一局部状态同时实现了相邻候选上的“同色互斥、异色允许”和连续两手的领先翻转。不过盘面仍有其他合法行动；该结构尚未证明能平铺、分叉或任意长串联，因此只能称为有限见证，不能称为 hardness gadget。

### 10.7 可完整证明的抽象 PSPACE-complete 核

定义一个明确不同于当前游戏的变体 \(\textsc{GUARDED-GRAPH-LIFELINE-NORMAL}\)：棋盘是输入图；只有指定候选顶点可落；每个候选顶点 \(v\) 邻接两个互不干扰的私有叶守卫 \(g_{v,B},g_{v,W}\)，分别预置为两色节点；保留当前三点限制，但删除长程线、攻击与领土，以“无合法落点者负”的 normal play 终局。

从无预着色 Col 做恒等式归约：

- 初始时，候选 \(v\) 对颜色 \(c\) 恰好邻接自己的一个孤立守卫，因而合法且有连接；
- 若源图相邻候选 \(u\) 已被 \(c\) 占据，则 \(v\) 同时邻接 \(g_{v,c}\) 与 \(u\)，三点限制使 \(v\) 对 \(c\) 非法；
- 对手占据 \(u\) 不增加 \(c\) 的相邻己方节点，所以不阻止 \(c\) 落 \(v\)；
- 已占候选不能重下。

因此两棵博弈树与 Col 完全同构。游戏长度至多为候选数，故该变体在 PSPACE；Col 的 PSPACE-hardness 给出 PSPACE-complete。

这项结果证明“三点限制的组合核心”足以承载 PSPACE-hardness，却不是当前 LIFELINE 的下界：它改变了棋盘、动作掩码、连线和终局。文献层面，Fenner 等人在 2015 年首次证明无预着色一般图 Col 为 PSPACE-hard；Burke 与 Tennenhouse 在 2025 年进一步证明三角网格图上的 Col 为 PSPACE-complete。

### 10.8 Superko 惰性引理与最小未闭合缺口

Superko 本身可以由单调标记处理：若每个模拟落子都在一个此前为空的专用点留下以后永不删除的节点，则不同模拟步后的物理层两两不同，完整哈希也不同；只要初始 \(H\) 不预含这些后继，模拟路径上永不触发 Superko。

从三角网格 Col 提升到当前完整规则，仍必须证明六件事：

1. **动作隔离。** 除逻辑候选外，所有空点、己方线点和敌方线点都不可落，或落后可证明立即失败；
2. **长程连线隔离。** 私有守卫不能与共轴远端节点产生跨构件边、占用候选或创造意外攻击口；
3. **守卫可达。** 守卫和隔离结构必须由两个真实基点经多项式长度合法历史构造，并保持根连通；
4. **可组合节拍。** 第 10.6 节的两步翻转要扩展到任意分支和任意深度，且贪心领土不能跨构件改分；
5. **终局对应。** 源 Col 无路可走的 normal-play 胜负必须等价于实际连续 Pass 后的面积胜负，自动跳过不能重新打开模拟；
6. **历史编码。** reachable 版本必须构造并证明一条真实行动序列，使其生成的 \(H\) 正是归约使用的历史；HISTORY 版本还必须显式输出该序列。

私有双守卫还占去候选点的两个相邻槽，直接端口只剩四个；若源 Col 构造使用六度三角网格顶点，还需要度数降低或复制端口 gadget。

若能多项式构造动作隔离、可达守卫、永久标记、任意长节拍、终局对应以及必要的度数降低或端口复制结构，就可从 Triangular-Grid-Col 推出

\[
\textsc{POSITION-LIFELINE-WIN}_{\mathrm{reach}}
\text{ 为 PSPACE-hard},
\]

进而也是 NP-hard。当前尚缺这些引理，所以最终状态仍是：**有严格的 PSPACE-hard 抽象核心和真实局部见证，但当前完整规则的任何 hardness 下界尚未证明。**

### 10.9 与围棋结果的严格对比

围棋是最接近的参照之一，但“围棋的复杂度”不是一个与规则无关的单一结论。至少必须区分：

- **Japanese basic/simple ko：** 只禁止紧接着恢复上一局面的立即回提；更长循环仍可能出现，三劫循环还可能被判无胜负。
- **Positional superko（PSK）：** 禁止产生任何曾出现过的棋盘着色，不区分下一行动方。
- **Situational superko（SSK）：** 只有棋盘着色与下一行动方都相同才算重复。
- **当前 LIFELINE：** 键包含下一行动方、认输集合、五态格点和每方显式边；因此是 situational-like，但又不同于围棋 SSK，而且 Pass 与 Resign 不写入 \(H\)。

已知结果应按其原问题口径引用：

| 对象与规则口径 | 已知严格结果 | 对 LIFELINE 能说明什么 |
|---|---|---|
| 任意给定 \(n\times n\) 围棋局面 | Lichtenstein–Sipser 证明判定赢家 PSPACE-hard；不是该文证明的 PSPACE-complete [6] | arbitrary-position gadget 是可行研究路线，但不能移植下界 |
| Robson 使用的 Japanese-rules/basic-ko 模型 | 1983 结果通常表述为：以任意预置局面为输入的广义强制获胜问题 EXPTIME-complete [9,11] | 证明依赖围棋的 liberty、capture、ko bank 与循环规则，不适用于 LIFELINE Superko |
| Chinese/superko 广义围棋，输入 position 只有石子配置且不附带既往禁用历史 | 2015 年综述记录为 PSPACE-hard 且属于 EXPSPACE，紧确分类在该综述中开放 [11] | 与本文的 EXPSPACE membership 最接近，但不是“任意显式 \(H\)”的同一个输入问题 |
| 围棋征子判定问题 LADDERS | 给定征子是否成立为 PSPACE-complete [10] | 自然局部机制也可能完整承载复杂度；具体 ko 口径按原论文定义，征子 gadget 不能复用于本游戏 |
| 空盘 \(5\times5\) PSK 围棋，komi \(=24.5\) | 2024 年给出先手满盘胜的完整计算机证明 [13] | 单个有限 START 实例的求解，不是广义 hardness 结论 |
| \(19\times19\) 静态合法棋盘着色 | 约 \(2.081681994\times10^{170}\) [12] | 不含行动方、Pass 计数与 \(H\)，不能当作完整规则状态数 |

Robson 的 EXPTIME-complete 结果不能只把“basic ko”替换成“superko”后继续引用；2015 年综述还提醒，传统 Japanese rules 对某些循环与终局情形本身并未给出完全统一的形式语义。Robson 1984 的通用 exponential-space 提升定理也只适用于满足其构造前提的一类已知 EXPTIME-complete 博弈 [14]；没有到特定 Go 或 LIFELINE 规则的归约，就不能推出 EXPSPACE-hard。本文没有在 2015 年综述之后确认到一个可安全引用的 PSK 紧分类闭合结果，因此只陈述该综述的历史状态，不把“开放”无条件写成截至任意未来年份的定理。

对边长 \(n\) 的围棋，令 \(N_G=n^2\)。PSK 的棋盘键数满足

\[
P_G^{\mathrm{PSK}}\le3^{N_G},
\]

SSK 则有

\[
P_G^{\mathrm{SSK}}\le2\cdot3^{N_G}.
\]

在“Pass 不触发重复检查、连续两次 Pass 终局”的双人 PSK 规则下，令 \(c_G\in\{0,1,2\}\)，可取

\[
\rho_G=3|H_G|+c_G.
\]

Place 增加一个新键并把 \(c_G\) 清零，非终局 Pass 增加 \(c_G\)，所以围棋的完整增广图同样是 DAG。成功落子至多为 \(P_G-1\)，显式路径历史占 \(2^{O(n^2)}\) 空间，朴素树给出 EXPSPACE 与双指数时间的安全上界。Japanese simple-ko 的当前位置投影却可含长循环，不能套用这个秩证明。

这与 LIFELINE 的定性结构相同，但尺度不同：围棋键主要由 \(n^2\) 个交叉点决定，而 LIFELINE 还要编码 \(\Theta(n^3)\) 个潜在长程显式边，因此安全键上界分别是

\[
2^{O(n^2)}
\quad\text{与}\quad
2^{O(n^3)}.
\]

这只是表示上界比较，不表示 LIFELINE 已经比围棋“更难”，也不提供任何 hardness 下界。

**零贴目 PSK 围棋的弱 Pass 窃取。** 对 Tromp–Taylor 的空盘、零 komi、面积计分 PSK 围棋，第 7.7 节的证明可以更干净地复用。反设后手 White 有严格必胜策略；Black 首手 Pass。White 若再 Pass 则和棋，所以它必须落 \(W(v)\)。实际历史的 PSK 集合是

\[
H_A=\{\varnothing,W(v)\}.
\]

反事实中 Black 从空盘直接走经换色棋盘自同构对应的 \(B(\theta v)\)，再把颜色与行动方交换，得到

\[
\widehat\Theta(H_C)=\{\varnothing,W(v)\}=H_A.
\]

Tromp–Taylor area score 是“己方石子数 + 只连通到己方的空点数”的集合定义，严格保持棋盘自同构与换色；空盘双 Pass 为和。反事实中 White 按假设策略严格获胜，换色后的实际终局就必须是 Black 严格获胜。这构造出一个能战胜该 White 策略的 Black 策略，与它能战胜所有 Black 策略矛盾。有限确定性于是推出 Black 至少不败。故：

\[
\boxed{\text{零 komi 的空盘 PSK 围棋中，后手不存在严格必胜策略。}}
\]

这一定理不需要“额外一颗己方棋子永远无害”。它反过来说明：**Superko 与 Pass 并不会自动破坏策略窃取；关键是两条模拟历史是否精确耦合。**

SSK 更接近 LIFELINE，因为键还含行动方。首 Pass 耦合的历史对称差为两个裸空盘 situation：

\[
D_0=\{(\varnothing,B),(\varnothing,W)\}.
\]

这里必须区分自杀规则。

**Pass 豁免且禁止自杀的 SSK。** 每个合法 Place 后，刚落下的棋子必然仍在盘上，所以候选 situation 不可能是空盘，\(D_0\) 永远不会被命中。在同样的零 komi、对称面积计分与双 Pass 终局条件下，上述弱 Pass 窃取证明也扩展到这种 SSK；不能笼统写成“SSK 使证明失败”。

**Pass 豁免且允许自杀的 SSK。** 历史差可以真实改变合法性。最小 \(1\times1\) 空盘见证中，初始历史含 \((\varnothing,B)\)。实际序列先由 Black Pass，White 再落唯一点并自杀，候选键仍是空盘且轮到 Black，即 \((\varnothing,B)\)，所以被 SSK 禁止；反事实中 Black 直接落该点并自杀，候选是 \((\varnothing,W)\)，它尚未出现，因而合法。于是同一换色应手只在一侧合法，镜像模拟确实分叉。这个例子证明 SSK 合法性分叉，不证明胜负值反转；在更大连通棋盘上，把一个连通己方块扩张到全盘仅余一气、再填最后一气整体自杀，也产生同类空盘键。

围棋搜索文献把“当前棋盘相同、历史不同而使合法着或值不同”的现象称为 Graph History Interaction（GHI）[13]。但 GHI 仍只给出第 7.10 节的合法性/策略分叉机制；除非构造出唯一保值应手被禁或 Minimax 值改变，否则它也不等于“策略窃取已经失败”。

围棋劫材还提供了恰当类比：simple ko 禁止立即回提，玩家可先在远处制造必须应对的劫材，再回提；PSK/SSK 虽检查全局历史，但远处交换改变了完整棋盘键，局部回提仍可能合法，直到整个键真正重复。LIFELINE 的 13 手见证同样表现为“直接恢复旧核被禁，制胜方必须先走别处”，但其三点限制、长程边与根连通删除不是围棋的气、提子或劫，故只能称为历史绕行类比，不能称为围棋 gadget。

最后，Tromp–Taylor area score 的集合定义天然镜像等变；固定给 White 的 komi 会有意破坏换色效用对称，Japanese territory scoring 还要纳入俘虏、死子确认与续弈约定。LIFELINE 第 7.8 节的 DRAW\(\to\)BLACK 反例来自同一 raw 算法的表示顺序，因此是另一类实现层不等变，不能用“围棋也有贴目”来掩盖。

## 11. 当前 AI 与强化学习视角

### 11.1 使用范围与搜索宽深

自动 AI 只用于本地双人局。界面难度对应深度：

\[
\text{简单}=2,\qquad
\text{普通}=3,\qquad
\text{困难}=4.
\]

提示固定使用深度 2。每个搜索节点先把合法落子分三档：

1. 覆盖敌方线点的攻击；
2. 与己方线点单位邻接的候选；
3. 其他落子。

每档内部保持棋盘格点的原始枚举顺序，合并后只保留前 20 手。正常 AI 返回评分最高的前 5 手，但界面只执行第一手。因此它是确定性的固定深度、固定宽度启发式 Alpha–Beta Minimax，不是完整博弈树求解器。

### 11.2 评估函数

固定 AI 玩家 \(a\)。定义节点差

\[
\Delta_N
=
|N_a|-\sum_{b\ne a}|N_b|,
\]

物理覆盖差

\[
\Delta_C
=
(|N_a|+|L_a|)
-
\sum_{b\ne a}(|N_b|+|L_b|).
\]

AI 还计算一个快速 BFS 可达空间 \(\widehat T_a\)：从全部己方节点和线点同时出发，只把敌方节点与线点视为障碍。它不是正式的轮廓—收紧—泛洪领土。

令 \(b^\star\) 为节点数最多的对手，并定义

\[
\Delta_T=\widehat T_a-\widehat T_{b^\star}.
\]

令 \(Q_a\) 为当前可合法攻击的敌方线点数，\(K_a\) 为己方节点沿显式边图连接到基点时记 \(+1\)、否则记 \(-1\) 的总和。叶节点启发值为

\[
h_a
=
15\Delta_N
+8\Delta_C
+20\Delta_T
+12Q_a
+10K_a.
\]

Worker 会禁用正式领土缓存更新，所以搜索依赖的是这个可达空间代理，而不是最终判胜 area。

### 11.3 与完整规则的差距

当前 AI 有以下理论限制：

- 搜索动作集只有 Place，不包含仍有合法落点时的主动 Pass，也不包含 Resign；
- 只有 legalMoves 为空时才手工模拟跳过，而且其逻辑不完全等价于真实 Normalize；
- 状态快照复制棋盘、显式边、历史、跳过数与领土缓存，但遗漏 resignedPlayers；
- 终局叶节点仍返回启发函数，不读取真实 winner，因此不保证有限深度内看见必胜时总会选择它；
- MAX/MIN 按递归层数机械翻转，而不是按 playMove 后的实际 currentPlayer 决定；若对手被自动跳过、同一玩家连续行动，控制权会建模错误；
- 前 20 手截断没有“最优手必在其中”的安全证明；
- 自动 AI 被 UI 限制在双人局，但三人局提示仍可能调用二元 Minimax；它既不是 Max-N，也不是严格的 Paranoid Search。

所以当前 AI 的正确描述是“使用真实引擎生成落子后继的截断启发式搜索”。保护区、真实三点限制、显式边攻击、级联删除和 Superko 都进入后继生成；但 Pass、Resign、真实终局效用、自动跳过后的控制权与三人理性没有被完整搜索。

### 11.4 更忠实的求解器方向

若要让 AI 与本文形式化一致，最低限度应：

1. 把 Place、Pass、Resign 全部加入动作集；
2. 通过公开规则转移或统一 Normalize 处理跳过；
3. 依据实际 currentPlayer 选择 MAX/MIN；
4. 终局使用 \(+1,0,-1\) 的真实效用；
5. 快照加入 resignedPlayers；
6. 将宽度截断改成可配置，并保留“完整模式”；
7. 三人局采用明确效用下的 Max-N、Paranoid 或均衡搜索；
8. 用显式边图的桥、割点、根边连通度和可能删除分量作为结构特征。

### 11.5 忠实的强化学习环境是一个增广 Markov game

固定规则配置

\[
\kappa=(n,m,\text{基点},\text{轮换次序},\text{起始玩家}),
\]

环境内部状态必须采用本文的完整 \(q\)。每个非终局决策状态的原始动作空间为

\[
\mathcal A_n
=
\{\operatorname{Place}(v):v\in\mathcal V_n\}
\cup
\{\operatorname{Pass},\operatorname{Resign}\}.
\]

实现时可对每个 \(n\) 使用 \(N(n)+2\) 个索引；也可为当前最大 \(n=15\) 固定 122 个索引，并在小棋盘屏蔽不存在的格点。合法掩码必须由真实引擎逐项给出，覆盖越界、已占节点、保护区、三点限制、无法连接、攻击规则、Superko、认输和终局，而不能由网络猜测。

一次 RL `step` 应定义为

\[
q'=T(q,a)=\operatorname{Normalize}(F(q,a)).
\]

自动跳过属于动作后的确定性 Normalize，不是智能体可选动作，也不应额外消耗一个折扣步。回合计时器造成的超时 Pass 是 UI/赛事协议层事件；除非显式研究时间控制，它不属于核心规则 MDP。

按有限回合强化学习的标准口径 [15]，二人模式最忠实的奖励是中间全为 0，终局才返回

\[
r_B=u_B(q_T),
\qquad
r_W=-r_B,
\qquad
\gamma=1.
\]

完整增广图是有限 DAG，所以无折扣回报良定义。取 \(\gamma<1\) 会人为加入“更快获胜、延迟失败”的时间偏好，不再精确表示当前规则。第 6.8 节说明二人最优训练可删去 Resign；Pass 必须保留。

### 11.6 定理：只看当前盘面与边的观测不是 Markov

定义历史盲观测

\[
o_X(q)=(\sigma,\mathbf E,\tau,R,c,z),
\]

即保留所有当前规则核字段而删去 \(H\)。第 7.10 节两条从标准初局可达的历史满足

\[
o_X(q_A)=o_X(q_B),
\]

但 White 的 \(W(1,1)\) 只在 \(q_A\) 合法，故

\[
M(q_A)\ne M(q_B).
\]

因此，通过 \(o_X\) 观察到的过程严格不是 MDP：同一观测连可用动作集都不能唯一决定。一个只接收当前格点、显式边和行动方的前馈策略，面对的是状态别名；把当前合法 mask 交给它能避免这一手走出非法动作，但尚无理由认为 mask 足以预测更深层的未来值。

有三种忠实处理方式：

1. 环境与搜索节点直接保留精确 \(H\)；
2. 给循环网络或 Transformer 完整动作/自动跳过事件序列，因为确定性引擎允许从 \(q_0,a_0,\ldots,a_{t-1}\) 精确重放出 \(q_t\)；
3. 若只给有限窗口或压缩观测，就明确把任务定义成 POMDP，并接受策略只是近似的。

合法性本身不能使用可能产生假阳性的 Bloom filter 或有碰撞的近似哈希；一次假阳性就等价于凭空增加 Superko 禁手。神经网络可以近似编码历史用于估值，但最终 action mask 应由保存完整 `historyHashes` 的引擎裁决。

精确搜索、回放缓存和去重至少应使用

\[
K_{\mathrm{full}}(q)
=
\bigl(
\kappa,
K_{\mathrm{position}}(\tau),
\operatorname{sort}(H),
c,z
\bigr).
\]

这里当前 `_computeStateHash` 已包含格点、每方显式边、下一行动方与 \(R\)，但不包含整个 \(H\)、\(c\) 或 \(z\)。`turnCount` 不参与核心规则，领土缓存可从规则状态重算，均不应替代上述字段。

### 11.7 值备份必须按真实控制权，而不是机械变号

一个 Place 后，Normalize 可能自动跳过没有合法落点的对手，使同一玩家连续获得两个决策回合。标准严格轮流棋类中常用的“树深每增加一层就把值取负”在这里不成立。

二人搜索最稳妥的是始终预测固定 Black 视角的 \(v_B\)：在 \(\tau=B\) 的节点取最大，在 \(\tau=W\) 的节点取最小，沿边传递 \(v_B(q')\) 而不按深度变号。若网络输出“当前行动者视角”标量，则只有在 \(\tau(q')\ne\tau(q)\) 时才交换视角；若自动跳过后仍是同一玩家，就不能变号。三人模式应直接备份

\[
\mathbf v(q)=(v_B(q),v_W(q),v_P(q)),
\]

并由节点的真实行动者优化自己的分量。

这不是抽象风险：当前 `AIEngine.js` 正是按递归层机械翻转 MAX/MIN，所以在自动跳过分支上会搜索错误的控制者。任何 AlphaZero 式 MCTS、PPO rollout 或离线回报生成器都必须从引擎返回的 `currentPlayer` 读取控制权。

### 11.8 适合当前规则的神经表示

单纯把三角棋盘当作图像会丢掉最关键的动态拓扑。一个更忠实的关系图/超图表示至少包括：

- 每个格点的 \(2m+1\) 态 one-hot、三角坐标、基点与保护区标记；
- 固定六邻接边；
- 每名玩家实际拥有的显式长边，附所有者、轴向和长度；
- 当前玩家、\(c\)、\(R\)、棋盘大小和玩家数等全局特征；
- 历史编码或可重放的完整行动序列。

为了让网络看见“未来可能连线”的共轴关系，不必显式输入全部 \(Q(n)=\Theta(n^3)\) 个端点对。可以为三族轴线各建立 \(n\) 个 line-hypernode，每个格点连接到自己所属的三个 line-hypernode；总入射数只有

\[
3N(n)=O(n^2),
\]

两跳消息传递即可在同轴点之间交换信息。实际显式边仍作为另一类动态关系输入。这是学习表示的稀疏化，不是把规则状态重新压回三态节点模型。

历史 JSON 哈希本身是无语义字符串，直接送入网络不利于泛化。更合理的近似包括对历次位置张量做集合/序列编码，或用循环状态重放；但无论采用哪种估值摘要，环境仍保留精确集合来判断 Superko。

对称数据增强也必须谨慎。第 7.6 节的非计分转移核支持换色反射 \(\Theta\)，但当前 winner 已有 `DRAW → BLACK` 反例。因此在修复计分前，可以用 \(\Theta\) 检查策略/转移一致性，却不能无条件把镜像终局当成换色后的同值监督样本，否则会把互相矛盾的标签注入 value 网络。

### 11.9 奖励塑形与 reward hacking

稀疏终局奖励最忠实，但样本效率可能很低。严格保持最优策略的一类稠密奖励是势函数塑形 [18]。对每名玩家 \(p\) 取所有终局上均为 0 的 \(\Phi_p\)，定义

\[
r'_p(q,a,q')
=
r_p(q,a,q')
+\Phi_p(q')-\Phi_p(q).
\]

一局总回报只比原回报多固定常数 \(-\Phi_p(q_0)\)，所以不改变从给定初局出发的策略排序。二人零和训练还应取 \(\Phi_W=-\Phi_B\)。节点数、连接到基点的分量、攻击机会和对称化后的领土代理都可以进入 \(\Phi\)，但必须通过这一差分形式使用，并在终局归零。

当前 AI 的 `fastTerritoryBFS`、节点增量或每步 raw area 增量并没有自动满足上述条件。把它们逐步直接奖励会鼓励可逆刷分、拖延终局，甚至牺牲真实胜负去追求代理指标。尤其当前贪心领土算法不保持镜像等变：若训练目标是“忠实击败当前实现”，智能体利用该偏差是合法最优行为；若目标是研究理想的公平游戏，就应先选择第 7.9 节的等变计分，再生成训练标签。强智能体暴露计分漏洞属于环境规格问题，不应误判成 RL 算法失败。

### 11.10 算法选择

| 方法 | 适用性 | 当前主要边界 |
|---|---|---|
| 精确逆向归纳、Alpha–Beta、证明数搜索 | 小型可解后缀的真值 oracle | 状态和历史爆炸，不能覆盖大棋盘 |
| AlphaZero 式 PUCT + 关系 GNN [16] | 二人确定、完全信息、零和版本的首选研究主线 | 必须包含 Pass、完整 action mask、真实控制权和历史感知转置键 |
| Masked PPO [19] | 易建立无搜索基线，可结合循环策略 | 自博弈非平稳、终局奖励稀疏、样本效率通常低于带规划方法 |
| DQN/分布式 Q-learning | 可用于极小棋盘或受限动作实验 | 大动作集、mask、长时程、自博弈非平稳和历史别名都不友好 |
| MuZero [17] | 可检验学习隐状态能否压缩复杂转移 | 已有精确模拟器，先学习模型通常增加误差而非解决首要瓶颈 |
| CFR 类方法 | 可作小盘扩展式策略审计 | 当前是完全信息顺序博弈，不具备让 CFR 成为首选的不完全信息结构 |
| Max-N、向量 MCTS、MAPPO、PSRO [20] | 明确效用后的三人研究 | 求解的是不同均衡/联盟模型，不能混用一个标量胜率比较 |

AlphaZero 式方法在这里也不是“已经会收敛到最优”的定理，只是最匹配现有精确模拟器、合法掩码与图结构的工程起点。MuZero 更适合作为后续历史压缩对照，而不是第一版环境。

### 11.11 训练课程与可证伪评测

建议按以下依赖顺序推进：

1. **环境一致性。** 实现公开的 `reset/clone/legalActionMask/step/fullStateKey`，快照必须加入 `resignedPlayers`，所有转移只调用真实 `playMove/skipTurn/resignPlayer`。
2. **小型 oracle 数据。** 从 \(n=5\) 的可达残局和受节点上限控制的 \(n=6\) 子树开始，用完整 Minimax 标注 \(V\) 与全部最优动作，而不是只模仿当前启发式 AI。
3. **基线。** 比较随机、当前深度 2/3/4 AI、Masked PPO 和 AlphaZero 式代理；至少跨多个随机种子与双方颜色报告。
4. **课程。** 按 \(n=5\to6\to7\) 扩大，再测试 9、12、15；逐步增加攻击、长边和长历史状态比例，保留旧策略池避免自博弈遗忘。
5. **三人阶段。** 只有在效用向量、联盟假设与均衡指标固定后再训练三人代理。

现有反例可以直接组成一个不可被平均胜率掩盖的单元基准：

| 基准 | 必须通过的行为 |
|---|---|
| `HISTORY-MASK` | 对同核异史两状态输出不同 Place mask，识别 \(W(1,1)\) 的 Superko 分叉 |
| `CYCLE-CUT` | 在 13 手状态拒绝会闭合八步环的 \(W(0,3)\) |
| `PASS-PRESSURE` | 在第 7.5 节状态选择唯一制胜的 Pass，而不是唯一 Place |
| `CONTROL-SKIP` | 对手自动跳过后仍由同一玩家决策，值备份不误变号 |
| `SYMMETRY-DEFECT` | 当前规则下复现原局 DRAW、镜像 BLACK；修复计分后该差距应归零 |
| `EXACT-ENDGAME` | 在可完整求解子树上匹配根值和最优动作集合，而不只匹配一个首选动作 |

最终报告至少应包含：胜/和/负率与置信区间、换色后的成对结果、对当前 AI 和历史策略池的表现、小残局 exploitability/最优动作召回率、value calibration、Pass 准确率、非法动作被 mask 前的概率质量、平均对局长度和搜索节点/时间。Elo 或自我对弈胜率只能说明相对强弱，不能替代小盘最优性证据。

推荐的消融实验是：`X-only + mask`、完整序列循环编码、显式历史编码三种观测；终局稀疏奖励与势函数塑形；图像 CNN、普通 GNN 与 line-hypernode 关系 GNN。每项至少使用 5 个训练随机种子，并把训练预算、对手池快照和评测残局固定下来。

### 11.12 三人多智能体学习的额外边界

三人代理必须先选择第 6.2 节的一套基数效用。一个标量 value head 加“当前玩家最大化”无法同时表达另外两人的利益；更忠实的是向量 critic、按实际行动者分量选择的 Max-N/向量 MCTS，或用 PSRO 在策略种群上构造经验元博弈。Paranoid Search 把另两人强行合并为联盟，解决的是派生二人零和问题，不是原始三方各自优化问题。

独立 PPO 会同时面对两个变化中的对手，易产生循环与策略遗忘；集中式 critic 或历史策略池能缓解，但不能替代效用与均衡定义。评测应报告每个座位、玩家置换、两方临时联盟下的鲁棒性以及经验博弈的 regret/NashConv 类指标，而不是只给总胜率。

第一名玩家认输后，剩余阶段也不是一盘干净的新二人游戏：认输者的节点、线、显式边和保护区仍留在棋盘并参与阻挡，只是该玩家不再行动且面积不参与 winner 比较。环境快照若像当前 Worker 一样遗漏 \(R\)，会把这些状态错误合并。

## 12. 尚待证明的研究边界

下一阶段最有价值的问题不是继续放大上界，而是收紧“可达结构”。

1. **可达显式边数。** 当前使用全部 \(Q(n)=\Theta(n^3)\) 个潜在边。三点限制、阻挡与首节点爬行是否把可达边集压到更小阶，仍未知。
2. **硬度归约。** 沿 Triangular-Grid-Col 路线闭合动作隔离、长程连线隔离、可达守卫、任意长计分节拍和终局对应；未完成前不得把抽象 PSPACE-complete 核升级成当前规则的下界。
3. **迫移分类。** \(Z=2\) 的实际 Pass-pressure 已经存在；仍可分类哪些结构产生压力、最小落子数是多少，以及 no-Pass 变体的 Zugzwang 是否能系统构造。
4. **历史价值反转。** 已有两条真实历史到达同一规则核却使 \(W(1,1)\) 只在一侧合法，也有一个精确制胜动作集从 3 缩为 2 的回环见证；仍需找到 \(V(X,H^-)\ne V(X,H^+)\)，或证明被禁动作是唯一不败/制胜应手，才能把“复制应手失效”升级为“策略价值失效”。
5. **对称性。** 精确面积和完整 winner 等变均已被第 7.8 节反例否定；仍需证明或反驳弱单向性质“\(W\) 胜 \(\Rightarrow\) 镜像后 \(B\) 至少不败”，并选择、实现一种严格等变计分。
6. **领土正确性。** 证明向内方案 A 所依赖的“当前覆盖无敌方元素”不变量，或者把该检查显式加入实现。
7. **紧复杂度。** EXPSPACE 只是 membership 上界；紧确类需要下界归约，甚至可能先通过受限变体得到 PSPACE-hard 或 EXPTIME-hard。
8. **实证搜索空间。** 通过可达状态枚举、转置表统计与真实对局记录测量平均分支因子、攻击率、自动跳过率和边集密度，不能把最坏情形上界当成典型值。
9. **条件分解。** 为一个非平凡可达区域证明动作局部性、根连通接口、计分可加性与 Superko 历史充分签名在所有后继下闭合；在此之前不能使用 nimber 异或或普通析取和。
10. **节拍谱。** 在可完整求解的小型子树上计算 \(U,D,Z\) 与 placement-tax threshold，研究其随棋盘大小、历史和边界接口的变化，但不把派生税谱冒充标准 Conway temperature。
11. **历史充分统计量。** 判断是否存在比完整 \(H\) 更小、却能同时保证当前合法性和未来值 Markov 性的精确摘要；仅有当前 action mask 尚无充分性证明。
12. **强化学习 oracle。** 建立固定可达残局集、完整最优动作集合和 exploitability 评测，再比较历史盲、循环历史与显式历史三类网络；当前没有正式训练结果。
13. **三人均衡。** 先固定基数效用、联盟和 tie-break，再比较 Max-N、向量 MCTS、MAPPO 与 PSRO；不同模型不能用一个“AI 胜率”混为同一问题。
14. **规则目标分叉。** 明确训练是要击败当前含计分不等变的实现，还是研究修复后的公平规则；两者的最优策略和对称数据增强标签可能不同。

## 13. 结论

当前 LIFELINE 已经可以被完整地描述为一个有限历史依赖图博弈：

\[
q=(\sigma,\mathbf E,\tau,R,c,H,z).
\]

二人版在明确胜负效用后是有限零和扩展式博弈；三人版是多玩家博弈，不应继续称为双人零和。显式边把忠实位置上界从纯格点模型的 \(2^{O(n^2)}\) 提高到 \(2^{O(n^3)}\)。Superko、认输和连续跳过共同给完整增广图提供严格秩，因此它是 DAG，并可逆向归纳。

显式位置/历史版强制获胜问题当前可放入 EXPSPACE，朴素时间为双指数上界；当前完整规则的任何 hardness 或完备性结论仍需真正归约。已经完成的是 Pass 消去引理、PSPACE-complete 的抽象 Col 核，以及当前引擎中的两步节拍/同色互斥见证；尚缺可组合与动作隔离证明。

策略窃取方面，三点限制严格否定了“额外己方棋子无害”的动作单调性。进一步地，当前引擎存在 \(Z=2\) 的可达 Pass-pressure：Pass 获胜而唯一 Place 在最优应对下失败。它证明了 Place-vs-Pass 的最大动作价值反转，但没有证明额外己方节点降低整个可比状态值；主动 Pass 也仍使“被迫落子”不成立。弱 Pass 窃取定理只需单向终局条件；当前完整 winner 等变已被 DRAW\(\to\)BLACK 的 10 手反例否定，而更弱的单向条件和标准初局先手不败仍开放。

历史方面已经取得更强但有明确边界的结果：两条标准初局可达历史能到达同一规则核，却使同一攻击只在一侧因 Superko 被禁；另一个可达八步环在增广图中被 Superko 截断。它们严格否定把历史盲逐动作复制当作普遍合法原则。精确 Minimax 则把反例强度限定为“制胜动作集从三个缩为两个，必须绕行”，而不是根值反转。标准首手 Pass 耦合只差永远不会命中的裸初始键，所以它并未被这些见证击穿。

围棋对比强化了同一边界：Japanese simple ko、PSK 与 SSK 必须分开；零 komi 的 Tromp–Taylor PSK 围棋甚至可严格证明弱 Pass 窃取和先手至少不败。围棋已有规则特定的 PSPACE-hard、EXPTIME-complete 和局部 PSPACE-complete 结果，但其预置局面、气、提子、征子与 ko-bank gadget 都不能迁移为 LIFELINE 下界。

组合博弈论的新视角进一步表明：完整 \(q\) 是可逆向归纳的短博弈，物理规则核 \(X\) 却没有独立于历史的选项集或值；普通 nimber、析取和和标准温度都缺少前提。可严格使用的是 \(U,D,Z,d_{\mathrm A},d_{\mathrm V}\) 以及派生的落子税谱。二人 Resign 可由弱支配消去，而 Pass 既控制终局时钟，又可能是唯一制胜动作。

强化学习的新视角把同一个历史分叉解释成严格状态别名：`X-only` 前馈观测不是 MDP。忠实代理必须让引擎保留精确 \(H\)，把自动跳过放进 Normalize，按真实 `currentPlayer` 备份，并以 \(\gamma=1\) 的终局胜负为基准。关系 GNN/line-hypernode 加 AlphaZero 式搜索是二人版的优先工程路线，但不是收敛定理；三人版需要效用向量与明确均衡概念。正式训练与实验比较仍是后续工作，本文没有把设计建议写成已取得的性能结果。

理论上的真正难点不只是状态多，而是四种结构同时耦合：三次规模的显式长程边、根连通级联删除、实现型 Superko 历史，以及离散贪心领土计分。后续证明和 AI 都必须在这个完整状态上工作。
