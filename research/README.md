# Research

This directory isolates research code, protocols, tests, and reproducibility
evidence from the playable application.

- [`iclr2027/`](./iclr2027/): LIFELINE-RL environment, search and AlphaZero
  baselines, representation experiments, paper source, and verified results.

Generated artifacts follow the repository policy in `AGENTS.md`: compact
formal summaries and verification evidence are versioned, while checkpoints,
raw trajectories, smoke runs, pilot runs, and temporary execution trees stay
local unless they are deliberately published through Git LFS or a release.
